# レンタルスペース収支シミュレーター

レンタルスペース事業(Javabronze とは別事業)の月次収支を、社長が自分で数字を変えて確かめるための道具。
依存なしの単一HTML。ネット接続もビルドも不要。

## 使い方

1. `index.html` をブラウザで開く(ダブルクリックでよい)
2. 左の入力欄を変えると、右側の結果がすぐに再計算される
3. 入力値はブラウザに保存される(`localStorage` のキー `rental-space-simulator:inputs:v3`)。「concept.md の初期値に戻す」で元に戻る。第3版でキーを変えたので、第2版の入力値は引き継がれない

スマホ幅では入力と結果が縦に並ぶ。ダークモードは端末の設定に従う。

## 計算式

営業時間(月)

- 1日の営業時間 `H = 閉店 − 開店`
- 早朝 = 月の日数 ×(早朝の終了 − 開店)(土日祝も含む毎日)
- 平日昼 = 平日数 ×(夜の開始 − 早朝の終了)、平日夜 = 平日数 ×(閉店 − 夜の開始)
- 土日祝 = 土日祝の日数 ×(閉店 − 早朝の終了)
- 合計 = 月の日数 × H(初期値で 510時間)

月次収支(12ヶ月目以降の定常状態。時間帯別の入力はこの状態を表す)

- 予約時間 = Σ(時間帯の営業時間 × 稼働率)
- 月売上 = Σ(時間帯の営業時間 × 稼働率 × 単価)
- 予約件数 = 予約時間 ÷ 平均利用時間
- 月利益 = 月売上 ×(1 − 手数料率)− 予約件数 × 清掃費 −(家賃 + その他固定費)
- 全体の稼働率 = 予約時間 ÷ 営業時間の合計、平均単価 = 月売上 ÷ 予約時間

損益分岐

- 1時間あたりの貢献利益 `c = 平均単価 ×(1 − 手数料率)− 清掃費 ÷ 平均利用時間`
- 損益分岐稼働率 = 固定費 ÷ c ÷ 営業時間の合計(初期値で約15%・月76時間)

回収(concept.md「前提(第3版)」の定義:累積の営業利益が初期投資に並んだ月)

- k ヶ月目の全体稼働率は、1ヶ月目・3ヶ月目・6ヶ月目の入力と、12ヶ月目(時間帯別の入力から出る全体の稼働率)を直線でつないだ値。13ヶ月目以降は12ヶ月目と同じ
- k ヶ月目の損益 = 稼働率 × 営業時間の合計 × c − 固定費。1ヶ月目だけ単価にオープニング割引をかける
- 平均単価は今の時間帯の比率で一定とする(concept.md の試算と同じ)
- 「回収する月」= 累積が初期投資以上になった最初の月(120ヶ月までに届かなければ回収不可)
- 「12ヶ月回収に必要な稼働率」= 1・3・6ヶ月目は入力のままで、12ヶ月目の累積がちょうど初期投資になる12ヶ月目の稼働率。12ヶ月の累積は12ヶ月目の稼働率の一次式なので、2点から解く
- 参考として「開業月から毎月同じ稼働率なら」の値 =(固定費 + 初期投資 ÷ 12)÷ c ÷ 営業時間の合計 も表示する(割引は無視)
- 「12ヶ月目の稼働率を変えたら」の表は、各時間帯の稼働率を同じ倍率で増減し(100%で頭打ち)、1・3・6ヶ月目は入力のままで計算する

撤退基準の判定(concept.md 第3版「撤退基準」)

| 時点 | 基準 | 判定に使う値 |
|---|---|---|
| 3ヶ月 | 12%未満で注意(写真・掲載文・価格の見直し)。20%が1年回収の目標 | 3ヶ月目の入力 |
| 6ヶ月 | 20%未満で黄信号(見直し 2ヶ月×2回まで)。30%が1年回収の目標 | 6ヶ月目の入力 |
| 見直し2回後 | 黄信号のうえ、10ヶ月目でも18%未満なら撤退判断 | 推移の10ヶ月目 |
| 12ヶ月 | 20%未満で撤退判断、20〜30%で条件付き継続、30〜40%で継続(目標40%未満)、40〜50%で継続(目標達成)、50%超で上振れ(3ヶ月続けば2室目の検討) | 12ヶ月目の稼働率 |
| 12ヶ月 | 1年回収の判定:累積が初期投資の100%以上で「12ヶ月で回収」、80%以上で「ほぼ計画どおり」、50〜80%で「計画より遅れ」、50%未満で「18ヶ月回収の計画へ」(これだけでは撤退しない) | 12ヶ月目の累積 |
| 18ヶ月 | 条件付き継続(12ヶ月で30%未満)のとき、30%未満なら撤退 | 18ヶ月目の稼働率 |
| 18ヶ月 | 初期投資を回収できているか(資金計画の前提) | 18ヶ月目の累積 |
| 随時 | 運転資金が固定費3ヶ月分(初期値で34.5万円)を割ったら撤退か縮小 | 運転資金 + 累積の赤字 |

- 第2版の表示の問題(12ヶ月30〜35%を単に「継続」、45%を「2年回収ペース」と出す)は解消した。30〜40%は「継続(目標40%未満)」と出し、回収の見込みは累積の計算(回収する月)で別に示す
- 即時撤退(大家・行政からの是正要求)は数字で判定できないので対象外
- 金額はすべて税抜。消費税・所得税・減価償却・季節変動は含まない

## テスト

```
node tools/rental-space-simulator/test.mjs
```

`index.html` の `<script id="calc">`(計算ロジック)を取り出して Node で評価し、concept.md 第3版の試算と照合する。照合している主な数字:

- 月510時間(早朝90・平日昼168・平日夜126・土日祝126)、損益分岐 月76時間・約15%
- 達成シナリオの月ごとの表(1ヶ月目 −6.2万 … 12ヶ月目 累積 +122.3万円で回収)
- 3つのシナリオ:達成=12ヶ月目、基本(単価2,500円)=13ヶ月目・累積約98万、慎重=20ヶ月目前後・累積約33万(慎重の1ヶ月目は concept.md に書かれていないので10%とした。8%だと21ヶ月目・約33万円)
- 12ヶ月の累積への影響:稼働率−5pt 約−46万、単価−200円 約−24万、清掃+500円 約−22万、家賃+1万 約−12万
- 単価2,500円なら初期投資95万円以下で12ヶ月回収
- 撤退基準の各境界と、以前の表示の問題が再発しないこと

計算ロジックを変えたら必ず実行すること。

- **初版からの主な変更**:シアター&撮影ルーム → **推し活(祭壇・上映)× 晩酌(ローテーブル・間接照明)**。撮影照明・背景紙スタンド・白い撮影床・簡易内窓・会議用の長机を削除。予算を95万円 → **48万円(内装25万円+家具・AV・家電23万円)**に。家具はリサイクルショップ中心

スクリーン│■                                        □│ 白の壁紙

藍の壁紙 │■                                        □│  副次の撮影背景)
        │■                                        □│
        │ [収納]  [窓:遮音カーテン]  [冷蔵庫・レンジ] [靴]ドア│

| 面 | 役割 | 仕上げ |
|---|---|---|
| **A スクリーン壁(西)** | 上映。部屋の主役 | 貼って剥がせる壁紙(藍色・マット)+スクリーン |
| **B 祭壇壁(北)** | 推しの祭壇・飾り付け。**スクリーンに近い西寄り半分に祭壇ラックを置き、ソファから画面と祭壇が同時に見える**ようにする | 有孔ボード(突っ張り柱)+ピクチャーレール+吸音パネル |
| **C 明るい壁(東)** | 早朝の身支度(全身鏡)、平日昼の副次的な撮影の背景 | 貼って剥がせる壁紙(白・マット) |
| **南(裏方)** | 冷蔵庫・電子レンジ・ケトル、分別ゴミ箱、収納、靴置き | 既存の壁のまま |

- 祭壇壁(B)は、物件が決まったら**隣室・共用廊下に接する長辺**に回す(吸音パネルと有孔ボードが音漏れ対策を兼ねるため)。

### 1-2. 基本配置「推しと晩酌」(平日夜・休日・一番の売れ筋)定員6名

```
        ┌──────────────────────────────────────────┐
        │ ▓祭壇ラック▓ ▓▓有孔ボード(推しカラーの飾り)▓▓ │
        │■  ┌スクリーン   ○スツール ○スツール         □│
        │■  │80〜100型  ┌──────────────┐ ┌─────┐  □│
        │■  │           │ こたつ風     │ │ソファA│  □│
        │■  │[サウンドバー]│ ローテーブル │ │2人掛 │  □│
        │■  └           └──────────────┘ │(画面向)│  □│
        │■  [プロジェクター]  ┌──ソファB 2人掛──┐└─────┘  □│
        │                   │(祭壇と画面を横目)│         │
        │ [収納]           └────────────┘ [冷蔵庫][ゴミ箱][靴]ドア│
        └──────────────────────────────────────── ─┘
```

- **L字配置**:ソファAは画面の正面、ソファBは南の壁に沿って北(祭壇)を向く。ローテーブルは全員の手が届く中央に置く
- スツール2脚はテーブルの北側。**座面35〜40cmの低いもの**にして、祭壇と画面をふさがない
- スクリーンの下端は床から80cm以上にし、スツールに座った人の頭で画面が欠けないようにする
- 視聴距離(ソファAから画面)は約2.5〜3.0m。100型の目安(画面の高さの2〜2.5倍)に収まる。部屋の短辺が2.5m未満なら80〜90型にする
- プロジェクターは**スクリーン手前の床置き(短焦点)か、ソファ後ろの棚置き**。天吊りの工事はしない
- 冷蔵庫・ゴミ箱はドア側にまとめる。**ゴミ出しの動線(テーブル → 分別ゴミ箱 → ドア → ゴミ置き場)が一直線**になり、22:30〜22:45の片付けが速く済む

### 1-3. 上映会配置(全員が正面を向く)

- ソファBをソファAの横に並べる(2人掛け約130cm × 2 = 約260cm。短辺3.0mに収まる)。スツールはテーブルの左右
- ローテーブルはソファの前に寄せ、飲み物に手が届く位置を保つ

### 1-4. 副次の配置(平日昼の会議・早朝の身支度)

- 会議:ローテーブルを北壁へ寄せ、折りたたみテーブル+折りたたみ椅子4脚+スツール2(concept U-11)。資料はプロジェクターに投影
- 早朝の身支度:東の明るい壁の前に全身鏡、照明シーン「身支度」(第3章)。飲酒不可の時間帯なので、テーブル上に何も置かない状態で引き渡す

### 1-5. 5分で切り替える仕組み

| 手順 | 作業 | 目安 |
|---|---|---|
| 1 | ソファB(脚なし・20kg以下・脚裏にフェルト)を動かす | 1分 |
| 2 | ローテーブル・スツールを動かす | 1分 |
| 3 | (会議のみ)折りたたみテーブル・椅子を出す | 2分 |
| 4 | 照明のシーンをボタン1つで切り替える | 10秒 |

- 床に**小さな角マーク**(剥がせるテープ)で家具の定位置を示す。清掃スタッフも「基本配置」に戻せるようにする
- 収納の扉裏に配置図2枚(基本・上映会)をA4ラミネートで貼る

## 4. 家具・家電の調達(リサイクルショップ中心)

### 4-1. 新品か中古かの区別(concept「中古で良いもの/新品にすべきもの」と同じ基準)

**火事・けが・衛生・セキュリティ・防炎の証明・壊れたら予約が飛ぶもの = 新品。それ以外 = 中古。**

| 新品にする | 中古で探す |
|---|---|
| プロジェクター・スクリーン・ケーブル・ストリーミング端末 | ソファ(**合皮のみ**) |
| カーテン・ラグ・タイルカーペット・吸音パネル(防炎ラベル付き) | ローテーブル(こたつ風)・折りたたみテーブル |
| 照明すべて・電源タップ・延長コード・消火器・救急箱 | スツール・折りたたみ椅子 |
| グラス・食器・トレー・電気ケトル | 祭壇ラック・収納ラック・靴ラック |
| クッション・クッションカバー(布製品) | 全身鏡 |
| 空気清浄機(脱臭フィルター) | 冷蔵庫・電子レンジ(条件付き)、サウンドバー(条件付き)、掃除機 |

- **買わない**:撮影照明・背景紙スタンド・モニター・ホワイトボード・布団・寝具・こたつのヒーター(第4-3)

### 4-2. 中古の品目ごとの選び方

| 品目 | サイズ | 色 | 状態のチェック(1つでも×なら買わない) |
|---|---|---|---|
| **合皮ソファ 2人掛け ×2** | 幅120〜140cm・奥行80cm以下・**座面高30〜38cm(ローソファ)**・脚なしか低い脚・20kg以下 | キャメル/ダークブラウン。**2台で色をそろえる**(同じ店で同じ系統を2台がベスト) | 座面の縁・肘の**合皮の剥がれ・ひび(加水分解)**がない/におい(たばこ・ペット)がない/座面のへたり・きしみがない/布張りは不可 |
| **こたつ風ローテーブル** | **家具調こたつの天板が狙い目**(75×105cm か 80×120cm、高さ35〜40cm)。6人で囲める大きさ | 木目のミドルブラウン | 天板の反り・ぐらつきがない/角の欠けがない/**ヒーターは使わない**(取り外して処分するか、店で本体のみ買う) |
| 折りたたみテーブル | 120×60cm前後・高さ70cm | 白かグレーか木目 | 脚のロックが確実にかかる |
| スツール ×2 | **座面高35〜40cm**・座面が拭ける素材 | 木部と同じ茶系か黒 | 4本脚のがたつきがない |
| 折りたたみ椅子 ×4 | 重ねて収納できる | 黒か木目で4脚そろい | 開閉の金具の錆・がたつきがない |
| **祭壇ラック** | 幅80〜90cm・奥行30cm・**高さ90cm以下**(画面をふさがない)・3段のオープン棚。ひな壇状ならなお良い | 木目か黒 | 棚板のたわみがない/**壁に固定しなくても倒れない低重心**のもの |
| 収納ラック(扉付き) | 高さ120cm以下 | 木目か白 | 扉の開閉がスムーズ |
| 靴ラック | 6人分(2〜3段) | 黒か木目 | — |
| 全身鏡(自立式) | 幅40cm以上 | 黒か木の枠 | ひび・欠けがない/スタンドが安定している |
| 冷蔵庫 | 1〜2ドア・45〜90L・冷凍室あり(氷用) | 白か黒 | **製造から5年以内・動作保証付き**/運転音が静か(店で確認)/庫内のにおい |
| 電子レンジ | 庫内フラット・ヘルツフリー | 白か黒 | **製造から5年以内・動作保証付き** |
| サウンドバー | 幅80〜100cm・サブウーファーなし | 黒 | **最大音量を制限できる機種であることを型番で確認**/HDMI ARC/リモコン付属 |
| 掃除機 | コード式(バッテリーの劣化がない) | 何でも | 吸引の動作確認 |

**買い回りのルール**

1. 買いに行く前に、部屋・エレベーター・ドアの**搬入できる寸法**(幅・高さ・奥行)をメモしていく
2. 「茶・黒・白」以外の色の家具は、どんなに安くても買わない
3. 2〜3店を回り、**先に大物(ソファ2台・ローテーブル)を決めてから**小物の色を合わせる
4. 家電は保証書・レシートを保管し、ai-admin の購入チェックリストで最終確認する

### 4-3. 中古なのに統一感を出すコツ

中古は形も木の色もばらばらになる。**「家具はそろえず、布・照明・小物でそろえる」**。

1. **布の色を2色に固定**:クッション(新品)・ラグ・カーテンを「テラコッタ+生成り」だけにする。家具の違いより布の色の方が写真で目立つ
2. **照明を電球色(2700K)に統一**:木の色の違い(明るいナラと濃いウォールナット)が暖かい光の中でなじむ。昼白色の電球を混ぜない
3. **高さをそろえる**:ソファ・テーブル・スツール・祭壇ラックを**床から90cm以下の低い家具**に統一する。部屋が広く見え、画面と祭壇が隠れない
4. **小物を1色でそろえる**:トレー・コースター・ゴミ箱・ティッシュケース・リモコン置きを黒(または木)に統一
5. **金物を黒にそろえる**:有孔ボードのフック・ピクチャーレール・フロアライトの脚
6. **増やさない**:飾りは祭壇壁だけに集め、ほかの壁には何も貼らない。余白が「きれいな部屋」に見せる

### 4-4. こたつ風にする理由と、本物のこたつを置かない理由

- 床に近い座卓+ローソファは「友だちの家で飲んでいる感じ」になり、晩酌の売りになる。写真でも居酒屋や会議室との違いがすぐ伝わる
- **こたつのヒーターとこたつ布団は使わない**:①居眠りが起きやすい(仮眠は不可のルール) ②中古の電熱器具とコードの発火リスク ③布団は飲み物をこぼすと洗えず、防炎の証明もできない
- 冬の「こたつ感」は、防炎ラグの厚みと電球色の照明で出す。暖房は物件のエアコンを使う。冬の利用状況を見て、ひざ掛けなどを置くかは開業後に判断する

## 5. 防音・近隣への配慮

本格的な防音工事はしない。**「音を出させない仕組み」+「漏れにくくする簡易対策」**。

### 5-1. 音を出させない仕組み

1. サウンドバーの最大音量を固定し、**22:00からはさらに下げる**(スマートリモコン)
2. サブウーファー・カラオケ機材・マイクは置かない
3. 騒音センサーの3段階の対応(concept ハウスルール8。機器は ai-admin)
4. 室内掲示に「22:00から静音タイム・22:30飲酒終了・22:45までにゴミ出し・23:00退室」(文面は ai-writer)

### 5-2. 漏れにくくする簡易対策

| 経路 | 対策 |
|---|---|
| 床 | 下敷きマット+タイルカーペット+ラグの3層。ソファは脚なし |
| 窓 | 床まで届く遮音カーテン(初版の簡易内窓は予算の都合で削除) |
| ドア | 隙間テープ・ドア下の隙間ふさぎ、ドアクローザーの速度を遅くする |
| 隣室側の壁 | 祭壇壁(有孔ボード+吸音パネル)を隣室側に回す |
| サウンドバー | 防振ゴムの上に置き、壁から10cm以上離す |

### 5-3. 共用部とゴミ

- 分別ゴミ箱の上に「ゴミ置き場までの道順」の写真付き掲示(撮影は photo-shotlist.md のカット18〜19)
- ドアの内側に「廊下・エレベーターではお静かに」の掲示(絵+文字)

## 6. 原状回復しやすい施工

| 部位 | やり方 | 退去時 |
|---|---|---|
| 壁(A面・C面) | 既存の壁紙の上に貼って剥がせる壁紙。**施工前に目立たない所で剥がし試験** | 剥がす |
| 祭壇壁 | 突っ張り柱に有孔ボードをビス留め(壁にはビスを打たない) | 柱ごと撤去 |
| 吸音パネル | 虫ピンか剥がせる両面テープ | 撤去 |
| 床 | 置き敷き(接着剤なし) | めくる |
| 照明 | 引掛シーリングに付けるだけ。LEDテープは配線モールごと剥がせる品 | 元の照明に戻す |

- 入居時に全面の写真を日付入りで保存する(ai-secretary が保管)
- 壁紙・突っ張り柱の可否は契約前に書面で確認(ai-admin の契約前チェック)
- 飾りは「有孔ボードのフック・ピクチャーレール・マスキングテープのみ可。壁へのセロテープ・画鋲は不可」とハウスルールに書く(ai-writer)

# 内装・レイアウト指示書(初版)

- 作成:ai-designer / 作成日:2026-09-26
- 前提資料:`docs/rental-space/strategy/concept.md`(コンセプト「6人までのシアター&撮影ルーム」、予算配分 第3-4章)
- 仮定:**15㎡・長方形(約5.0m × 3.0m)・天井高2.4m・窓1つ・ドア1つ・既存の引掛シーリング2か所とコンセント4口以上**。物件が決まったら実寸で引き直す
- 予算:内装50万円 + 家具・AV・撮影照明45万円 = **95万円以内**(スマートロック・カメラ等の12万円は別枠で ai-admin が選定)
- 方針:**壁・床・天井に穴を開けない、電気工事をしない**。すべて「置く・突っ張る・貼って剥がす」で作る

## 1. レイアウト案(テキスト図・上から見た図、1マス ≒ 25cm)

### 1-1. 壁の役割(ゾーニング)

```
                    北の長辺(5.0m) = 【C 装飾壁】有孔ボード+ピクチャーレール
        ┌───────────────────────────────────────────────┐
        │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
西の短辺 │■                                             □│ 東の短辺
(3.0m)  │■                                             □│ (3.0m)
【A      │■                                             □│【B
シアター │■                                             □│ 白壁撮影面】
面】     │■                                             □│
濃紺壁+  │■                                             □│ マット白+
100型    │■                                             □│ 床に白シート
スクリーン│■                                             □│
        │   [収納ラック]   [窓:防音カーテン]  [ミニキッチン]  ドア│
        └────────────────────────────────────────────┘ ─┘
                    南の長辺(5.0m) = 窓・入口・収納(生活動線)
```

- **A シアター面(西の短辺)**:濃い色の壁+100インチスクリーン。映像のコントラストを上げ、写真の1枚目になる面
- **B 白壁撮影面(東の短辺)**:マットな白壁(幅約2.4m)+床に白いシート。物撮り・人物・動画撮影用
- **C 装飾壁(北の長辺)**:有孔ボードとピクチャーレール。推し活の飾り付けをする面。シアター写真の画角にも入る
- **南の長辺**:窓・入口・収納・ミニキッチン(ケトル・小型冷蔵庫)。撮影の画角から外す「裏方」の面
- A と B を向かい合わせにすることで、**シアター利用中は背中側に白壁が隠れ、撮影利用中はスクリーンを巻き上げて背景から外せる**

### 1-2. シアター配置(平日夜・休日)定員6名

```
        │▓▓▓▓ 装飾壁(ガーランド・アクスタ・ぬいぐるみ)▓▓▓▓▓│
        │■                                             □│
        │■ ┌スクリーン     ○プーフ                      □│
        │■ │100型     [プロジェクター                   □│
        │■ │          (短焦点・床置き台)]  ┌─────┐ ┌─────┐ □│
        │■ │ [サウンドバー] [ローテーブル] │ソファ│ │ソファ│ □│
        │■ └          ○プーフ          │2人掛│ │2人掛│ □│
        │■                           └─────┘ └─────┘ □│
        │  [ラック]      [ラグ 200×250]    [冷蔵庫]  ドア │
        └────────────────────────────────────────────┘ ─┘
          ←── 視聴距離 約2.5〜3.2m(100型の目安は画面高さの2〜2.5倍)──→
```

- 席:ローソファ2人掛け×2(4名)+プーフ×2(2名)= **6名**
- 短焦点プロジェクターをスクリーン手前の低い台に置く → **人が前を横切っても影が出ない、天吊り工事が不要**
- 折りたたみテーブル・チェアは南側の収納ラック横に畳んで立てる

- 会議:折りたたみ机+チェア4脚+プーフ2 = 6名。スクリーンに資料を投影できる
- 撮影:机を西寄りに置き、**東側1.5m分の床を空ける**。撮影照明2灯は南北の角に置く

### 1-4. 5分で切り替える仕組み

| 手順 | 作業 | 目安 |
|---|---|---|
| 1 | ソファ(軽量・脚なし、フェルト付き)を北壁に寄せる/戻す | 1分 |
| 2 | 折りたたみ机・チェアを出す/しまう | 2分 |
| 3 | ラグを丸める/敷く(撮影時のみ) | 1分 |
| 4 | 照明シーンをボタン1つで切り替える(第3章) | 10秒 |

- 床に**養生テープで家具の定位置マーク**(小さな角マーク)を貼り、清掃スタッフも戻せるようにする
- 収納ラックの扉裏に、2パターンの配置図(A4ラミネート)を貼る

## 2. 配色

| 部位 | 色 | 参考色(目安) | 理由 |
|---|---|---|---|
| A シアター面の壁 | ミッドナイトネイビー(マット) | #1F2A44 | 映像の周りを暗くしてコントラストを上げる。写真で「映画館らしさ」が一目で伝わる |
| B 白壁撮影面 | ニュートラルホワイト(**マット・黄みなし**) | #F4F4F2 | 光沢があるとテカリが写る。黄み・青みのある白は肌色と物の色がずれる |
| C 装飾壁(有孔ボード) | ウォームグレージュ | #CFC4B6 | 飾りの色を邪魔しない中間色。どの推しカラーでも映える |
| 南の長辺・残りの壁 | 既存の白壁のまま | — | 施工費を抑える |
| 床 | タイルカーペット チャコールグレー | #4A4A4A 系 | 汚れが目立ちにくい、防音、部分交換できる |
| 撮影床(東1.5m) | 白のクッションフロア(置き敷き) | 白 | 物撮りで壁と床をつなげて見せる |
| ソファ・ファブリック | テラコッタ or マスタード | #C8664A / #D9A441 | 写真のアクセント。ブランドのアクセント色(brand-and-banners.md)と合わせる |
| 金物・フレーム | ブラック | — | 締まって見え、指紋が目立ちにくい |

- 色の数は **「ネイビー・白・グレージュ+アクセント1色」まで**。装飾で利用者の色が加わる前提なので、部屋自体は控えめにする

## 3. 照明(調光・色温度)

### 3-1. 機材

| 照明 | 仕様 | 置き場所 |
|---|---|---|
| メイン照明 ×2 | 調光・調色のLEDシーリング(2700〜6500K、12畳以下用)、リモコン・スマートリモコン対応 | 既存の引掛シーリング2か所 |
| 間接照明 | LEDテープ 電球色2700K、調光つき、USBかコンセント給電 | スクリーン裏の壁の上下・装飾壁の上端(貼って剥がせる両面テープ+配線モール) |

| シーン名(ボタン表示) | メイン照明 | 間接照明 | 撮影照明 | 使う場面 |

| 上映 | 消灯 | 2700K・10% | 消灯 | 上映会・スポーツ観戦 |
| パーティー | 3000K・50% | 2700K・100% | 消灯 | 誕生日会・推し活 |
| 会議 | 5000K・100% | 消灯 | 消灯 | 会議・勉強会・面接 |

## 5. 防音・近隣配慮の工夫

本格的な防音工事はしない(concept.md 第5章 #8)。**「音を出させない仕組み」+「漏れにくくする簡易対策」**の2段構えにする。

### 5-1. 音を出させない仕組み(一番効く)

1. **サウンドバーの最大音量を固定**(機種の音量上限機能。上限値は開業前に隣室・廊下で聞いて決める)
2. **サブウーファーを置かない**。低音は壁を伝わりやすいため
3. 騒音センサーのしきい値を超えたら、利用者のスマホに自動で注意メッセージが届く設定にする(機器は ai-admin が選定)
4. 室内掲示・入室案内に「音量上限あり・22時退室・共用部での会話禁止」を明記(文面は ai-writer)
5. カラオケ機材・マイクは置かない

### 5-2. 漏れにくくする簡易対策

| 経路 | 対策 |
|---|---|
| 床(下の階) | 遮音マット+タイルカーペットの2層。ソファは脚なしにして振動を伝えない |
| 窓 | 遮音カーテン(床まで届く長さ)+DIYの内窓 |
| ドア | 隙間テープ、ドア下の隙間ふさぎ、ドアクローザーの速度を遅くして「バタン」を防ぐ |
| 壁(隣室) | 隣室に接する壁に吸音パネルと有孔ボード(装飾壁)を配置。装飾壁は隣室側の長辺を優先する |
| スピーカー | サウンドバーを防振ゴムの上に置き、壁から10cm以上離す |

- 物件が決まったら、**どの壁が隣室・共用廊下に接しているか**を確認し、装飾壁(C)と吸音パネルの位置を入れ替える

### 5-3. 共用部での配慮

- ドアの内側に「退室時はお静かに」の掲示(絵+文字)
- 入口前にゴミを置かせない。ゴミは室内の分別ゴミ箱に入れて清掃スタッフが回収

## 6. 原状回復しやすい施工

| 部位 | やり方 | 退去時の作業 |
|---|---|---|
| 壁(A面・B面) | 既存の壁紙の上に**貼って剥がせる壁紙**。施工前に目立たない場所で剥がし試験をする | 剥がすだけ |
| 装飾壁(C面) | 突っ張りアジャスター+2×4材の柱に有孔ボードをビス留め(**壁にはビスを打たない**) | 柱ごと撤去 |
| ピクチャーレール | 突っ張り式 | 撤去 |
| 吸音パネル | 虫ピン(細い針)か剥がせる両面テープ | 撤去。ピン穴は通常損耗の範囲か契約時に確認 |
| 床 | 置き敷きの遮音マット+タイルカーペット(接着剤なし) | めくって撤去 |
| 照明 | 既存の引掛シーリングに取り付けるだけ。LEDテープは配線モールごと剥がせる品 | 取り外し、元の照明を戻す |
| スクリーン | 自立式か突っ張り式 | 撤去 |
| 窓 | カーテンは既存のレールに、内窓は置き型・突っ張り型 | 撤去 |

- **入居時の写真を全面撮影して保存**(壁・床・天井・設備。日付入り)。原状回復の範囲でもめないため(ai-secretary が記録保管)
- 原状回復の範囲と「貼って剥がせる壁紙」「突っ張り柱」の可否は、**契約前に管理会社へ書面で確認**(ai-admin の契約前チェックに追加する)
- 装飾キットは「マスキングテープ・有孔ボードのフック・ピクチャーレールのみ使用可」とし、**壁への直接の貼り付け(セロテープ・画鋲)は禁止**とハウスルールに書く(ai-writer)

## 7. 物件決定後にやること

1. 実寸図面で第1章を描き直す(窓・ドア・コンセント・隣室側の壁の位置)
2. 視聴距離からスクリーンのサイズを確定(部屋の短辺が2.5m未満なら80〜90型に落とす)
3. 見積もりを取り直し、95万円を超える場合は第4章の「削る順番」で調整
4. 施工後、`photo-shotlist.md` の撮影へ進む

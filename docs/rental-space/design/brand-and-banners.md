## 2. ブランドカラー

内装(interior.md 第2章)と同じ色を使い、写真とバナーの印象をそろえる。

| 役割 | 名前 | HEX | 使い道 |
|---|---|---|---|
| メイン | ミッドナイトネイビー | #1F2A44 | 背景・ロゴ・見出し。シアター面の壁と同じ色 |
| ベース | ポップコーンクリーム | #F6EFE3 | 明るい背景・余白 |
| アクセント1 | スポットライトアンバー | #E0A33A | ボタン・強調・ロゴの光のモチーフ。**ネイビー背景の上でのみ文字に使う** |
| アクセント2 | カーテンテラコッタ | #C8664A | 推し活・誕生日の投稿のアクセント。ソファの色と合わせる |
| 補助 | スタジオホワイト | #FFFFFF | 撮影系の投稿の背景 |
| 補助 | グレージュ | #CFC4B6 | 区切り線・装飾壁の写真となじませる |

### 色の組み合わせルール(読みやすさ)

| 文字色 / 背景色 | 可否 | メモ |
|---|---|---|
| ネイビー / クリーム・白 | ◎ | 本文・料金など小さな文字はこれ |
| クリーム・白 / ネイビー | ◎ | カバー画像の見出し |
| アンバー / ネイビー | ○ | 見出し・強調のみ(太字・24px以上) |
| アンバー / クリーム・白 | × | コントラスト不足。使わない |
| 白 / テラコッタ | ○ | 太字の短い文字のみ |
| 白文字 / 写真の上 | △ | 必ずネイビー60%の帯か影を敷く |

- 用途の区別(シアター/撮影/会議)は**色だけに頼らず、必ず文字ラベルかアイコンを添える**

## 3. ロゴ

### 3-1. 構成

```
   ┌───────────┐
   │  ◢■■■◣   │  ← シンボル:横長の四角(スクリーン)の右上から
   │  ■ 6 ■   │     アンバーの光が斜めに差す。中央に「6」
   │  ◥■■■◤   │
   └───────────┘
     ROOM6            ← ロゴタイプ:欧文サンセリフ太字
   THEATER & STUDIO   ← サブ:細字・字間を広げる(トラッキング +200)
```

- シンボル:16:9 の角丸四角(ネイビー)の中に、白抜きの数字「6」。右上からアンバーの三角形の光(スポットライト)
- ロゴタイプ:「ROOM6」をサンセリフの太字(Canva:Montserrat Bold / Poppins SemiBold など)
- サブ表記:「THEATER & STUDIO」細字。日本語併記が必要な場所では「シアター&スタジオ」(Canva:Noto Sans JP Medium / M PLUS 1p など)

### 3-2. バリエーション(Canvaで4種類を書き出す)

| 種類 | 背景 | 用途 | 書き出し |
|---|---|---|---|
| 横組み・カラー | 透明 | 掲示物・資料・チラシ | PNG(透過)・幅1200px |
| 横組み・白抜き | 透明 | ネイビー背景・写真の上 | PNG(透過)・幅1200px |
| シンボルのみ・カラー | ネイビー | SNSアイコン | PNG・1080×1080 |
| シンボルのみ・単色 | 透明 | 小さな表示(ファビコン・スタンプ) | PNG(透過)・512×512 |

- 最小サイズ:シンボル単体で幅24px。これより小さいと「6」が潰れる
- ロゴの周りに、シンボルの高さの1/4以上の余白を空ける
- やってはいけないこと:縦横比の変更、色の入れ替え、影・グラデーションの追加、写真の上にそのまま置く(帯なし)

## 4. フォントと文言の共通ルール

| 用途 | フォント(Canva内) | 太さ |
|---|---|---|
| 日本語の見出し | Noto Sans JP / M PLUS 1p | Bold |
| 日本語の本文 | Noto Sans JP | Regular〜Medium |
| 英字・数字 | Montserrat / Poppins | SemiBold〜Bold |

- 1枚の画像に使うフォントは2種類まで
- 文言に「No.1」「最安」「日本一」「完全防音」を使わない(根拠がない表示は景品表示法の問題になる。**防音は「簡易防音」「音量上限つき」と書く**)
- 他人の著作物(映画・アニメの画像、キャラクター、アーティスト写真)を使わない。推し活は「推しカラーで飾れる」「上映会」など**一般的な言葉**で表す
- 料金を入れる画像は、価格改定のたびに差し替えが必要なのでストーリーズとハイライトだけにする

## 5. ポータルのカバー画像・掲載画像

### 5-1. 基本方針

- ポータルの**1枚目は写真のみ(文字なし)**。photo-shotlist.md のカット1を使う
- 文字入り画像は、ポータルの規約で認められている場合だけ2枚目以降に入れる。**掲載前に各ポータルのガイドライン(文字入れ・ロゴ・外部誘導・推奨サイズ)を ai-researcher が確認**する
- 外部サイト・SNS・電話番号・QRコードは画像に入れない(ポータルの直接取引禁止の規約に触れるおそれ)

### 5-2. マスターサイズ

| 用途 | サイズ | 比率 | メモ |
|---|---|---|---|
| ポータル掲載写真(マスター) | 1920×1280px | 3:2 | 中央の1706×1280(4:3)と1280×1280(1:1)に主役を収める |
| 規約で許される場合の「特徴まとめ」画像(2枚目以降) | 1920×1280px | 3:2 | 下記5-3 |

### 5-3. 特徴まとめ画像(文字入り・規約で可の場合のみ)

```
┌──────────────────────────────────────────┐
│ [写真:カット2 上映中の雰囲気、全面]           │
│                                          │
│  ┌─ネイビー60%の帯(左側 40%幅)─┐             │
│  │ 100インチの大画面で           │             │
│  │ 6人だけの上映会               │             │
│  │                              │             │
│  │ ▶ 100インチ シアター          │             │
│  │ ▶ 飾り付けOKの壁              │             │
│  │ ▶ 白壁の撮影スペース          │             │
│  │ ▶ 定員6名・音量上限つき        │             │
│  └──────────────────────────────┘             │
└──────────────────────────────────────────┘
```

- 見出し:クリーム色 #F6EFE3、Noto Sans JP Bold 72px
- 箇条書き:白 48px、先頭の▶はアンバー
- 写真の主役(スクリーン)は右側に来るよう配置する

## 6. Instagram

### 6-1. プロフィールアイコン

- サイズ:1080×1080px で作成(表示は円形に切り抜かれる)
- 内容:シンボルのみ・カラー(ネイビー背景・白い「6」・アンバーの光)。**円の内側80%にシンボルを収める**
- 文字「ROOM6」は入れない(小さくて読めないため)

### 6-2. フィード投稿テンプレート(4:5)

- サイズ:**1080×1350px**
- 開業時に3種類のテンプレートをCanvaで作り、毎回写真と文字を差し替える

| テンプレ | 用途 | 構図 | 背景 | 文言の例 |
|---|---|---|---|---|
| T1 部屋紹介 | 開業告知・用途紹介 | 上70%が写真、下30%がネイビーの帯。帯に見出し1行+サブ1行、右下に小さくロゴ(白抜き) | ネイビー | 見出し「6人だけのシアタールーム」/ サブ「○○駅徒歩3分・100インチ」 |
| T2 飾り付け例 | 推し活・誕生日の実例 | 写真を全面、左上にテラコッタの角丸ラベル(白文字) | 写真 | ラベル「飾り付け例」/ 下部に「推しカラーで飾れる壁」 |
| T3 撮影プラン | 平日昼の撮影・会議 | 白背景、中央に物撮りの作例写真、上にネイビー文字の見出し | 白 | 見出し「白壁で、そのまま撮れる」/ サブ「平日昼の撮影・会議に」 |

- 文字の安全範囲:上下各150px・左右各80pxには重要な文字を置かない(プロフィール一覧で上下が切れるため、グリッド表示は3:4で中央が残る)
- 見出し:60〜72px、本文:36〜44px
- カルーセル(複数枚)の場合、1枚目はT1、最後の1枚は「ご予約はプロフィールのリンクから」(ネイビー背景・クリーム文字)

### 6-3. ストーリーズ(9:16)

- サイズ:**1080×1920px**
- 安全範囲:上250px・下340pxにはスタンプ・文字を置かない(プロフィール表示と返信欄に隠れる)
- 定番の3種

| 種類 | 構図 | 文言の例 |
|---|---|---|
| 空き枠のお知らせ | 上半分に部屋の写真、下半分クリーム背景にネイビー文字の日付リスト | 「今週の空き」「10/4(土)10:00〜15:00」 |
| 利用のようす | 写真全面+下部にネイビー帯 | 「誕生日会でご利用いただきました」(**利用者の許可を取ったものだけ**) |
| 料金のご案内 | ネイビー背景、中央にプラン表(クリーム文字、価格はアンバー) | 「休日5時間パック 14,800円」(価格は concept.md 第2章の最新値) |

### 6-4. ハイライトカバー

- サイズ:**1080×1920px**(表示は中央の円形のみ)
- **中央の直径約600pxの円の中にアイコンを置く**。円の外には何も置かない
- 背景色:全カバー共通でネイビー #1F2A44。アイコンはクリーム #F6EFE3 の線画(線の太さをそろえる)
- ハイライト名は色ではなく**文字(下のラベル)で区別**する

| 順 | ハイライト名(ラベル) | アイコン(Canvaの素材検索語) | 中身 |
|---|---|---|---|
| 1 | お部屋 | 家・ソファ(sofa line icon) | 全景・配置2パターン |
| 2 | シアター | スクリーン・プロジェクター(projector line icon) | 上映会の様子 |
| 3 | 飾り付け | ガーランド(garland line icon) | 推し活・誕生日の飾り付け例 |
| 4 | 撮影 | カメラ(camera line icon) | 白壁・作例 |
| 5 | 料金 | 円マーク・チケット(ticket line icon) | 料金・パック |
| 6 | アクセス | 地図のピン(map pin line icon) | 駅からの道順・入口 |
| 7 | ルール | 音量マーク(volume line icon) | 定員・22時退室・音量上限・禁止事項 |

## 8. 室内のウェルカム画面(スクリーンに映す静止画)

- サイズ:**1920×1080px**(プロジェクターの解像度に合わせる)
- 背景:ネイビー、中央に白抜きロゴ、下に「ようこそ ROOM6 へ」「Wi-Fi:○○ / PASS:○○」「退室は○○時までにお願いします」
- 文字は最小48px(3m離れて読める大きさ)
- 撮影(photo-shotlist.md)のときにスクリーンに映す映像としても使う

## 9. 制作の順番と納品

1. ロゴ4種(第3章)→ 社長が確認
2. プロフィールアイコン・ハイライトカバー7枚(第6章)
3. フィードテンプレートT1〜T3、ストーリーズ3種
4. X ヘッダー・ウェルカム画面
5. 写真撮影(photo-shotlist.md)が終わったら、写真を差し込んで開業告知の投稿を3本作る(文面は ai-writer)

- Canvaのデザインは1つのフォルダ「ROOM6_brand」にまとめ、ブランドカラー6色を「ブランドキット」に登録する(無料版で使えない場合はカラーパレットをこのHEXで手入力)
- 書き出し:SNSはPNG、写真主体の画像はJPEG(画質80以上)
- **公開・投稿・アカウント作成は社長の確認後**に行う

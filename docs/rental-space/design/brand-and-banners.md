## 1. スペース名の案(ビジュアルの観点から)

ai-writer も名前案を出す。ここでは「ロゴにしたとき・サムネイルの小さな文字で読めるか」「推し活と晩酌の両方が見た目で伝わるか」で評価した。

| 案 | 名前 | 読み | ビジュアルの評価 | 推奨 |
|---|---|---|---|---|
| **A** | **推しと晩酌** | おしとばんしゃく | 検索語が2つとも入り、**説明なしで用途が伝わる**。漢字・ひらがなの配分が良く、「と」を小さくすると2語が並ぶロゴになる。縦書きにも横書きにもできる | **◎ 推奨**(concept の第1候補と一致) |
| B | おしばん | — | 4文字で丸く、アイコンやスタンプにしやすい。ただし意味が伝わらないので、**必ず「推しと晩酌の部屋」の副題が要る** | ○ Aの**愛称・SNSのハッシュタグ**として併用 |
| C | 推し見酒 | おしみざけ | 花見酒・月見酒のもじりで、名前だけで「推しを見ながら飲む」情景になる。和風のロゴにしやすい。ただ読み方が一瞬迷う | ○ 次点 |
| D | 推しのみ部屋 | おしのみべや | 「推し飲み」と「推しのみ(推しだけ)」の掛けことば。親しみやすいが、「飲み部屋」が大人数の飲み会を連想させる(concept が見送った用途) | △ |
| E | ちゃぶ台と推し | — | こたつ風ローテーブルの写真と一致し、イラストのロゴにしやすい。**晩酌の意味は弱い**ので副題「晩酌できる推し部屋」が要る | △ |

- 掲載名は「**推しと晩酌|◯◯駅徒歩◯分|大画面で上映会・家飲み|6名まで**」(concept の形式。文面の最終版は ai-writer)
- 以下は案Aで書く。B〜Eに決まった場合も、色・フォント・レイアウトの規則はそのまま使える

## 2. ブランドカラー

内装(interior.md 第2章)と同じ色にして、写真とバナーの印象をそろえる。**「夜の藍に、電球色のあかり」**が軸。

| 役割 | 名前 | HEX | 使い道 |
|---|---|---|---|
| メイン | 晩酌の藍 | #1F2A44 | 背景・ロゴ・見出し。スクリーン壁と同じ色 |
| ベース | 生成り | #F6EFE3 | 明るい背景・余白・藍の上の文字 |
| アクセント1 | あかりのアンバー | #E0A33A | ロゴの光(月・グラスの反射)、藍の上の強調 |
| アクセント2 | 暖簾のテラコッタ | #C8664A | 推し活・生誕祭の投稿のラベル。クッション・カーテンと同じ色 |
| 補助 | 木のブラウン | #7A5436 | ちゃぶ台・木部のイラスト、区切り線 |
| 装飾のみ | ペンライトの帯 | 7色(赤・橙・黄・緑・青・紫・ピンク)の細い線 | **推しカラーは人によって違うので1色に決めない**。ロゴの下やバナーの縁に、細い7色の帯として少しだけ使う。文字には使わない |

### 色の組み合わせ(読みやすさ)

| 文字 / 背景 | 可否 | メモ |
|---|---|---|
| 藍 / 生成り・白 | ◎ | 本文・料金など小さな文字はこれ |
| 生成り / 藍 | ◎ | 見出し(コントラスト比 約12:1) |
| アンバー / 藍 | ○ | 見出し・強調のみ(太字・24px以上。約6:1) |
| アンバー / 生成り・白 | × | コントラスト不足 |
| 白 / テラコッタ | ○ | 太字の短いラベルのみ(約3.9:1) |
| 白 / 写真 | △ | 必ず藍60%の帯を敷く |

- 用途(推し活/晩酌/上映/身支度)は**色だけで区別せず、必ず文字ラベルかアイコンを添える**

## 3. ロゴ

### 3-1. 方向性(2案。推奨はX)

| 案 | シンボル | 印象 | 小さくしたとき |
|---|---|---|---|
| **X(推奨)** | **三日月の内側に、ペンライトが1本立つ**。月=晩酌の夜、ペンライト=推し活。月はアンバー、ペンライトは生成り、先端に7色の小さな点 | 静かな夜・大人の推し活。「騒がない部屋」の約束とも合う | 形が単純なので24pxでも潰れない |
| Y | グラスの中の飲み物に、ペンライトの光が映り込む | 晩酌が前に出る | 細部が多く、アイコンでは潰れる。バナーの挿絵向き |

- 避ける表現:ジョッキの乾杯・泡があふれるビール・酔った顔(大人数の飲み会や飲みすぎを連想させ、ハウスルールと矛盾する)

### 3-2. 構成(案X+名前A)

```
     ☾|         ← シンボル:アンバーの三日月+生成りのペンライト
   推しと晩酌     ← ロゴタイプ:「推し」「晩酌」を同じ大きさ、「と」を60%の大きさ
   ─────────     ← 7色の細い帯(ロゴタイプの幅と同じ・線の太さは文字の線の半分)
  OSHI & BANSHAKU  ← サブ:欧文の細字・字間を広げる(トラッキング +200)
```

- ロゴタイプの書体:丸みのある和文の太字(Canva:Zen Maru Gothic Bold / M PLUS Rounded 1c Bold)。**明朝は居酒屋、角ゴシックは会議室の印象になる**ので避ける
- 縦書き版も作る(ウェルカム画面・室内の掲示・ストーリーズ用)

### 3-3. バリエーション(Canvaで書き出す)

| 種類 | 背景 | 用途 | 書き出し |
|---|---|---|---|
| 横組み・カラー | 透明 | 掲示物・資料 | PNG(透過)幅1200px |
| 横組み・白抜き | 透明 | 藍の背景・写真の帯の上 | PNG(透過)幅1200px |
| 縦組み・白抜き | 透明 | ウェルカム画面・ストーリーズ | PNG(透過)高さ1200px |
| シンボルのみ・カラー | 藍 | SNSアイコン | PNG 1080×1080 |
| シンボルのみ・単色 | 透明 | 小さな表示 | PNG(透過)512×512 |

- 最小サイズ:シンボル単体で幅24px/ロゴタイプ込みで幅120px
- 周りの余白はシンボルの高さの1/4以上
- 禁止:縦横比の変更、色の入れ替え、影・グラデーションの追加、写真の上に帯なしで置く

## 4. フォントと文言のルール

| 用途 | フォント(Canva内) | 太さ |
|---|---|---|
| 見出し | Zen Maru Gothic / M PLUS Rounded 1c | Bold |
| 本文 | Noto Sans JP | Regular〜Medium |
| 英字・数字 | Poppins / Montserrat | SemiBold |

- 1枚に使うフォントは2種類まで
- 「No.1」「最安」「完全防音」は使わない。**防音は「音量上限つき」「22時から静音タイム」**と書く
- **お酒の表現**:「飲み放題」「朝まで」「オール」「一気」は使わない。「持ち込みで晩酌」「家飲みの代わりに」と書く。お酒を扱う画像には小さく「20歳未満の飲酒は法律で禁止されています」を入れる。銘柄のラベルは写さない
- 推し活は「推しカラーで飾れる」「祭壇を作れる棚」「上映会」など**一般的な言葉**で表し、作品名・人物・キャラクター画像は使わない
- 料金の入った画像はストーリーズとハイライトだけにする(改定のたびに差し替えるため)
- 時刻の表記は concept 第3版に合わせる:**入室6:00〜退室23:00/22:00から静音/22:30飲酒終了/早朝(6〜9時)は飲酒不可**

## 5. ポータルの掲載画像

- **1枚目は写真のみ(文字なし)**:photo-shotlist.md のカット1「推しと晩酌 全景」
- 文字入り画像は、ポータルの規約で許される場合だけ2枚目以降(規約の確認は ai-researcher)。外部サイト・SNS・電話番号・QRコードは入れない
- マスターサイズ:1920×1280px(3:2)。中央4:3と1:1に主役(画面と祭壇)を収める

### 特徴まとめ画像(規約で可の場合のみ・1920×1280)

```
┌──────────────────────────────────────────┐
│ [写真:カット5 推しを見ながら晩酌、全面]        │
│  ┌─藍60%の帯(左40%)──────┐                 │
│  │ 推しを観ながら、          │                 │
│  │ 6人でゆっくり晩酌         │                 │
│  │ ▶ 大画面(80〜100インチ)   │                 │
│  │ ▶ 祭壇を作れる棚と壁       │                 │
│  │ ▶ こたつ風のローテーブル    │                 │
│  │ ▶ 持ち込み自由・冷蔵庫あり   │                 │
│  │ ▶ 定員6名・22時から静音     │                 │
│  └──────────────────────┘     20歳未満の飲酒は… │
└──────────────────────────────────────────┘
```

- 見出し:生成り、Zen Maru Gothic Bold 72px/箇条書き:白 48px、先頭の▶はアンバー

## 6. Instagram

### 6-1. プロフィールアイコン(1080×1080)

- シンボルのみ(藍の背景・アンバーの三日月・生成りのペンライト)。円の内側80%に収める。文字は入れない

### 6-2. フィード投稿(4:5・1080×1350)

| テンプレ | 用途 | 構図 | 文言の例 |
|---|---|---|---|
| T1 部屋紹介 | 開業告知・用途紹介 | 上70%が写真(カット1)、下30%が藍の帯に見出し+サブ、右下に白抜きロゴ | 「推しと、晩酌。」/「◯◯駅徒歩◯分・6名まで」 |
| T2 祭壇の例 | 推し活・生誕祭の実例 | 写真全面、左上にテラコッタの角丸ラベル(白文字) | ラベル「祭壇の例」/「推しカラーで飾れる棚」 |
| T3 晩酌の例 | 仕事帰り・家飲みの代わり | 生成りの背景、中央にカット4(こたつ風テーブル)、上に藍の見出し | 「今夜は、家飲みの代わりに」/「平日夜3時間パック」 |

- 文字の安全範囲:上下150px・左右80pxに重要な文字を置かない
- 見出し60〜72px、本文36〜44px
- カルーセルの最後は「ご予約はプロフィールのリンクから」(藍の背景・生成りの文字)

### 6-3. ストーリーズ(9:16・1080×1920)

- 安全範囲:上250px・下340pxに文字を置かない

| 種類 | 構図 | 文言の例 |
|---|---|---|
| 空き枠のお知らせ | 上半分に写真、下半分は生成りの背景に藍の日付リスト | 「今週の空き」「10/4(土)15:00〜20:00」 |
| 利用のようす | 写真全面+下部に藍の帯 | 「生誕祭でご利用いただきました」(**利用者の許可を取ったものだけ**) |
| 料金のご案内 | 藍の背景にプラン表(生成りの文字、価格はアンバー) | 「平日夜 晩酌3時間パック 7,800円」(価格は concept 第3版の最新値) |
| 静音タイムのお知らせ | 藍の背景、中央に三日月のシンボル | 「22時からは静音タイム。22時30分でお酒はおしまい」 |

### 6-4. ハイライトカバー(1080×1920、中央の直径約600pxの円の中にアイコン)

- 背景は全部藍、アイコンは生成りの線画。**名前(下のラベル)で区別**する

| 順 | ラベル | アイコン(Canvaの検索語) | 中身 |
|---|---|---|---|
| 1 | お部屋 | ソファ(sofa line icon) | 全景・配置2種 |
| 2 | 推し活 | ペンライト(glow stick line icon) | 祭壇・上映会・生誕祭 |
| 3 | 晩酌 | グラス(glass line icon) | こたつ風テーブル・持ち込みの例 |
| 4 | 朝の利用 | 太陽(sun line icon) | 遠征の朝の身支度・観戦 |
| 5 | 料金 | チケット(ticket line icon) | 料金・パック |
| 6 | アクセス | 地図のピン(map pin line icon) | 駅からの道順・入口 |
| 7 | ルール | 三日月(moon line icon) | 定員6名・23時退室・22時から静音・22:30飲酒終了・ゴミの出し方 |

## 8. 室内のウェルカム画面(スクリーンに映す静止画・1920×1080)

- 藍の背景、左に縦組みの白抜きロゴ、右に案内。文字は最小48px(3m離れて読める大きさ)
- 案内の内容(文面は ai-writer):「ようこそ」/Wi-Fi/**退室は23:00まで/22:00から静音タイム/22:30でお酒はおしまい/ゴミは分別して22:45までにゴミ置き場へ(道順は入口の掲示)**
- 早朝(6〜9時)用に「本日の早朝枠は飲酒不可です」の版も作る
- 撮影(photo-shotlist.md)で画面に映す映像としても使う

## 9. 制作の順番

1. 名前の決定(社長)と商標の確認(ai-researcher)を待つ。それまでは案Aで下書きだけ作る
2. ロゴ5種(第3章)→ 社長が確認
3. アイコン・ハイライトカバー7枚
4. フィードT1〜T3・ストーリーズ4種
5. X ヘッダー・ウェルカム画面2種(通常・早朝)
6. 撮影後、写真を差し込んで開業告知の投稿を3本(文面は ai-writer)

- Canvaのフォルダ名は「oshi-banshaku_brand」(名前が決まったら変更)。ブランドカラー5色+7色の帯をパレットに登録
- 書き出し:SNSはPNG、写真主体はJPEG(画質80以上)
- **公開・投稿・アカウント作成は社長の確認後**

- **ずれた場合の読み替え**:申込日がずれたら、以降の日付は「申込日+8週=入居日、入居日+6週=D」で平行移動する
- 立ち上げが遅れると1年回収は遠のく(concept 3-3、analytics 次の打ち手1)。**ただし必須条件を満たさない物件で急ぐより、遅れを選ぶ**(1室しかないため、契約解除は投資の全損に近い。O-18)

### 5-1. クリティカルパス(1つ遅れると開業日がそのまま遅れる順路)

```
候補駅の件数(R3-016)→ 比較表(R3-103)→ 候補駅の決定 O-12(R3-104, 10/17)
```

- **全体を止める最大の点は「書面承諾」**。3つの書面(A1〜A3)が1つでも取れなければその物件は見送りで、F1 に戻る。口頭の「たぶん大丈夫」は△のままで、契約しない(viewing-checklist 第0章)

- **3番目はポータル審査**。審査期間は【未確認】(R3-015 で確認)。写真と掲載文がそろわないと申請できないので、撮影日が実質の締切
- **準クリティカル(遅れやすい外部の手続き)**:光回線の開通(申込から数週間〜1ヶ月以上。契約直後に申込、遅れたらモバイルルーター)、使用開始届(D−7【法定】)、工事計画届(着工7日前【法定】、内装工事がある場合)

## 抜け漏れのリマインド(ai-secretary・2026-09-27)

- **3人体制で新しく決めることがある**:役割と「社長=最終決定者」(R3-002)、出資・分配・名義などお金のルール(R3-003)。既存の decisions-for-owner.md には項目がないので、承認されたら `O-41` などとして追加を提案する
- **既存資料の「社長が行う」を3人に割り振り直す必要**:opening-checklist の担当欄、concept 第6章 #7(壁紙DIY・初期清掃)、plan A1(社長の作業 週1時間)は1人前提のまま。本書の担当で読み替え、確定後に ai-admin・ai-marketer に修正を依頼する
- **開業日の前提が変わる**:tasks.md と decisions-for-owner.md は「D ≒ 2026-12-19」。本書は 2027-03-13 を提案。承認されたら tasks.md の冒頭と O-24 の推奨案を更新する。開業が約3ヶ月遅れる分、1年回収の判定時期と資金の底の時期も後ろにずれる(ai-analyst に確認を依頼)
- **人件費はゼロ前提**:concept の収支は3人の作業時間を費用に入れていない。利益の分け方(R3-003)を決めるときに、清掃を B が多く担う分の扱いも決める
- **担当が1人に決まっていない**:RS-150(候補駅の件数)は ai-marketer・ai-researcher の分担が未定だったが、本書では B が画面で数え、集計を ai-marketer とした(統括本部長の確認待ち)
- **一次情報の確認は人が行う**:商標(J-PlatPat)・ポータル規約・手数料は、AI のネットワーク制限で開けない可能性があるため C が画面で確認する前提にした

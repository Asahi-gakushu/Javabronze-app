# ゲスト向けメッセージ定型文(第3版対応)

- 作成:ai-writer / 初版:2026-09-26 / 第3版対応:2026-09-26
- 前提:`docs/rental-space/strategy/concept.md` 第3版、`content/listing.md`(ハウスルール)
- 【】は差し込み欄です。予約ごとに置き換えてから送ってください
- ポータルのメッセージ機能で送る想定です。外部サイト・個人連絡先への誘導は、ポータル規約を確認するまで入れていません
- 共通の差し込み欄:【お名前】【ご利用日】【開始時刻】【終了時刻】【人数】【プラン名】【スペース名】【駅名】

### 第3版で直したこと

- 「22:00までに退室」→「**23:00退室**(22:00から静音タイム、22:30に飲酒終了)」
- 「ゴミはすべてお持ち帰り」→「**分別して、建物の24時間ゴミ置き場へ**。退室の15分前まで」。道順の写真と退室時の写真(室内+ゴミ置き場)を追加
- 入室は「10分前から」→「**ご予約の開始時刻から**」
- お酒の注意(20歳未満の飲酒禁止・飲酒運転の防止・泥酔者の入室不可)を追加
- 新しい定型文:早朝枠の承認・お断り(1-2・1-3)、静音タイムのお知らせ(2-2)、騒音の3段階(4-1〜4-3)、泥酔・20歳未満の飲酒(4-4・4-5)

## 2. 前日リマインド(入室方法・ゴミの案内つき)

【お名前】様

明日のご利用について、入室方法をお送りします。

■ ご予約内容
- ご利用日:【ご利用日】
- ご利用時間:【開始時刻】〜【終了時刻】
- 人数:【人数】名

■ 入室方法
- 住所:【住所・建物名・階・部屋番号】
- 最寄り駅:【駅名】【◯】出口から徒歩【◯】分
- 地図:【地図URL】
- 建物への入り方:【例:1階エントランスの右側のエレベーターで◯階へ】
- 暗証番号:【暗証番号】(ご予約の開始時刻から終了時刻まで使えます)
- 鍵の開け方:【例:ドアのテンキーに触れて点灯させ、番号を入力し最後に◯を押す】
- 照明・プロジェクターの使い方:室内のテーブルに説明書があります

■ ゴミの捨て方
ゴミは室内のゴミ箱で分別し、建物のゴミ置き場(24時間出せます)へ捨ててください。

- 分別:燃やすゴミ/缶/瓶/ペットボトル【出し方の詳細:例「缶・瓶・ペットボトルは中をすすぐ」】
- ゴミ置き場の場所:【例:1階エレベーターを降りて左、裏口の手前の扉】
- 道順の写真:【写真1:部屋の前】【写真2:エレベーター】【写真3:ゴミ置き場の扉】【写真4:区分ごとの置き場所】
- 出し終える時刻:**退室の15分前まで**(23:00退室なら22:45まで)
- 分別できない物・大量のゴミ(段ボールをたくさん・瓶をケースごと など)は、お持ち帰りください
- 地域の家庭ゴミの集積所やコンビニのゴミ箱には捨てないでください

■ お酒について
- 飲めるのは11:00〜22:30です。早朝(6:00〜9:00)は飲酒できません。
- 20歳未満の方の飲酒は、法律で禁止されています。
- お酒を飲んだ方は、車・バイク・自転車を運転しないでください。お帰りは電車・タクシー・運転代行でお願いします。
- 泥酔している方の入室はお断りしています。一気飲みや、飲酒の強要はしないでください。

■ お願い
- 暗証番号は、ご一緒に利用する方以外には伝えないでください。
- 建物の前での待ち合わせはご遠慮ください。全員そろってから入室するか、先に着いた方から静かに入室してください。
- 廊下・エレベーター・ゴミ置き場では会話を控えてください。同じ建物で過ごしている方がいます。
- 22:00からは静音タイムです。サウンドバーの音量上限が自動で下がります。
- 退室の前に、室内の「退室チェックリスト」をご確認ください(下の3でも案内します)。

■ 当日の連絡先
困ったことがあれば、このメッセージ【または:緊急連絡先 ◯◯】にご連絡ください。【対応時間:◯:00〜◯:00】
体調が急に悪くなった方がいるときは、ためらわずに119番へ連絡してください。

明日、楽しい時間になりますように。

【スペース名】運営

## 5. トラブル時の定型文

### 5-1. 騒音センサーが反応したとき(第1段階・自動メッセージ)

【お名前】様

ご利用中に失礼します。室内の音量が大きくなっているようです。
同じ建物で過ごしている方がいるため、音量と声を少し落としていただけますか。
【22:00以降の場合:ただいま静音タイム中です。】
ご協力をお願いします。

### 5-2. 騒音が続くとき(第2段階・お電話の前後に送る)

【お名前】様

先ほどお電話【またはメッセージ】でお伝えしたとおり、音量の大きい状態が続いています。
ハウスルールのとおり、このあとも改善されない場合は、ご退室をお願いし、違約金をいただくことになります(返金はありません)。
ただちに音量を下げていただくよう、お願いします。

お電話で話す内容(運営用メモ):名乗る → 音量が大きい状態が続いていると伝える → 次は退室をお願いすることになると伝える → 下げてもらえるか確認する。強い口調にしない。

### 5-3. ご退室のお願い(第3段階)

【お名前】様

2回お願いしましたが、音量の大きい状態が改善されませんでした。
ハウスルールにより、ご利用を終了させていただきます。【◯分以内】にお片付けとゴミ出しをして、ご退室ください。
ご利用料金の返金はありません。違約金【◯円】を【ポータル経由】でご請求します。
退室の際は、共用部では静かにお願いします。

### 5-4. 泥酔している方がいるとき

【お名前】様

【入口のカメラ / ご連絡】で、【お酒に酔って足元がふらついている方】がいらっしゃるように見えました。
ハウスルールにより、泥酔している方の入室・滞在はお断りしています。安全のため、その方にはお帰りいただくよう、お願いします。

体調が悪そうなときは、ひとりにしないでください。意識がはっきりしない、呼びかけに答えないなどのときは、ためらわずに119番へ連絡してください。
お帰りの際は、車・バイク・自転車を運転しないでください。

### 5-5. 20歳未満の方の飲酒を確認したとき

【お名前】様

【確認した内容】により、20歳未満の方がお酒を飲んでいることを確認しました。
20歳未満の方の飲酒は、法律で禁止されています。ハウスルールにより、ご利用を終了させていただきます。【◯分以内】にお片付けをして、ご退室ください。
ご利用料金の返金はありません。

### 5-6. 定員超過・時間超過・飲酒時間の違反が確認されたとき

【お名前】様

【確認した内容:例「定員(6名)を超える人数の入室」「22:30を過ぎての飲酒」「早朝の時間帯での飲酒」「退室時刻23:00を過ぎてのご利用」】が確認されました。
ハウスルールにより、【対応:例「6名を超える方は退室をお願いします」「お酒を終わりにしてください」「ただちに退室をお願いします」】。
【延長料金・違約金が発生する場合:◯円をポータル経由でご請求します】
ご理解とご協力をお願いします。

### 5-7. 入室できないと連絡が来たとき

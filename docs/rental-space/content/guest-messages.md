# ゲスト向けメッセージ定型文(初版)

- 作成:ai-writer / 作成日:2026-09-26
- 【】は差し込み欄です。予約ごとに置き換えてから送ってください
- ポータルのメッセージ機能で送る想定です。外部サイト・個人連絡先への誘導は、ポータル規約を確認するまで入れていません
- 共通の差し込み欄:【お名前】【ご利用日】【開始時刻】【終了時刻】【人数】【プラン名】【スペース名】【駅名】

---

## 1. 予約確定

【お名前】様

このたびは【スペース名】をご予約いただき、ありがとうございます。
以下の内容で予約が確定しました。

- ご利用日:【ご利用日】
- ご利用時間:【開始時刻】〜【終了時刻】(準備・片付けの時間を含みます)
- 人数:【人数】名(定員6名)
- プラン:【プラン名】

入室方法(住所・暗証番号)は、ご利用日の前日【18:00】ごろにお送りします。

ご利用の前に、ハウスルールをもう一度ご確認ください。特に大切な点は次の4つです。

1. 定員は6名です。
2. パーティー・上映会のご利用は22:00までに退室をお願いします。
3. サウンドバーは音量の上限を設定しています。廊下やエレベーターでは会話を控えてください。
4. ゴミはすべてお持ち帰りください。宿泊・仮眠はできません。

飾り付けや機材の持ち込みについてご質問があれば、このメッセージにお気軽にご返信ください。
当日を楽しみにお待ちしています。

【スペース名】運営

## 2. 前日リマインド(入室方法つき)

【お名前】様

明日のご利用について、入室方法をお送りします。

■ ご予約内容
- ご利用日:【ご利用日】
- ご利用時間:【開始時刻】〜【終了時刻】
- 人数:【人数】名

■ 入室方法
- 住所:【住所・建物名・階・部屋番号】
- 最寄り駅:【駅名】【◯】出口から徒歩【◯】分
- 地図:【地図URL】
- 建物への入り方:【例:1階エントランスの右側のエレベーターで◯階へ】
- 暗証番号:【暗証番号】(ご利用時間の【10】分前から使えます)
- 鍵の開け方:【例:ドアのテンキーに触れて点灯させ、番号を入力し最後に◯を押す】
- 室内の照明・プロジェクターの使い方:室内のテーブルに説明書があります

■ お願い
- 暗証番号は、ご一緒に利用する方以外には伝えないでください。
- 建物の前での待ち合わせはご遠慮ください。全員そろってから入室するか、先に着いた方から静かに入室してください。
- 廊下・エレベーターでは会話を控えてください。近くでお仕事をしている方がいます。
- 退室時は、室内の「退室チェックリスト」をご確認ください。

■ 当日の連絡先
困ったことがあれば、このメッセージ【または:緊急連絡先 ◯◯】にご連絡ください。【対応時間:◯:00〜◯:00】

明日、楽しい時間になりますように。

【スペース名】運営

## 3. 利用後のお礼とレビュー依頼

【お名前】様

本日は【スペース名】をご利用いただき、ありがとうございました。
きれいにお片付けいただき、次の方にも気持ちよく使っていただけます。【片付けが不十分だった場合はこの一文を削除】

まだ始まったばかりのスペースのため、いただいた声を一つずつ改善に生かしています。
もしよろしければ、ご利用の感想をレビューでお聞かせください。

- よかったところ(画面の大きさ、飾り付け、写真の撮りやすさなど)
- 使いにくかったところ、あったらうれしい備品

レビューは【ポータル名】の「ご利用履歴」から書くことができます。

また、推しのお祝いや上映会、撮影の機会があれば、ぜひお待ちしています。

【スペース名】運営

【具体的に触れられた点:例「飾り付けの写真」】を拝見して、とてもうれしく思いました。
またのご利用を心よりお待ちしています。

### 3-2. レビューへの返信(改善の指摘)

【お名前】様、ご利用とご意見をありがとうございます。
【指摘の内容】の件、ご不便をおかけして申し訳ありませんでした。【対応内容:例「◯月◯日に◯◯を追加しました」】
いただいた声をもとに改善を続けます。またお越しいただけたらうれしいです。

## 4. トラブル時の定型文

### 4-1. 騒音センサーが反応したとき(1回目)

【お名前】様

ご利用中に失礼します。室内の音量がやや大きくなっているようです。
近くにお住まい・お仕事中の方がいるため、少しだけ音量と声を落としていただけますか。
ご協力をお願いします。引き続き楽しい時間をお過ごしください。

### 4-2. 騒音が続くとき(2回目・最終のお願い)

【お名前】様

先ほどもお知らせしましたが、音量の大きい状態が続いています。
ハウスルールのとおり、改善されない場合はご利用を途中で終了していただくことになります(返金はありません)。
ただちに音量を下げていただくよう、お願いします。

### 4-3. 定員超過・時間超過が確認されたとき

【お名前】様

【確認した内容:例「定員(6名)を超える人数の入室」「退室時刻22:00を過ぎてのご利用」】が確認されました。
ハウスルールにより、【対応:例「6名を超える方は退室をお願いします」「ただちに退室をお願いします」】。
【延長料金・追加清掃費が発生する場合:◯円をポータル経由でご請求します】
ご理解とご協力をお願いします。

### 4-4. 入室できないと連絡が来たとき

【お名前】様

ご不便をおかけして申し訳ありません。次の点をご確認ください。

1. 入室できるのはご利用時間の【10】分前からです。
2. 暗証番号は【暗証番号】です。【テンキーの操作手順】の順で入力してください。
3. 部屋番号が【部屋番号】で合っているか、ご確認ください。

それでも開かない場合は、このメッセージ【または:緊急連絡先 ◯◯】にご連絡ください。すぐに対応します。
入室できなかった時間分は、【返金 / 延長】で対応します。

### 4-5. 設備の故障があったとき(ゲストからの連絡への返信)

【お名前】様

ご連絡ありがとうございます。【設備名】が使えずご不便をおかけして申し訳ありません。
【対処方法:例「リモコンの電源を一度切り、30秒後に入れ直してください」】をお試しください。
解決しない場合は、ご利用できなかった分について【返金 / 一部返金】で対応します。後ほど改めてご連絡します。

### 4-6. 退室後に片付け・破損の問題が見つかったとき

【お名前】様

先日はご利用ありがとうございました。
清掃の際に、【内容:例「ゴミの置き忘れ」「壁のテープ跡」「◯◯の破損」】が見つかりました。【写真を添付します】
ハウスルールにもとづき、【対応:例「追加の清掃費◯円」「修理費◯円」】をご負担いただきたく、ご連絡しました。
お心当たりの点やご事情があれば、【◯日】までにご返信ください。

### 4-7. 忘れ物があったとき

【お名前】様

先日はご利用ありがとうございました。
室内に【忘れ物の内容】のお忘れ物がありました。【保管期限:◯日間】保管しています。
受け取り方法(着払いでの郵送など)をご返信ください。

### 4-8. 運営側の都合で利用できなくなったとき

【お名前】様

大変申し訳ありません。【理由:例「設備の故障」「建物の緊急点検」】により、【ご利用日】のご利用ができなくなりました。
お支払いいただいた料金は、全額返金いたします。【返金の時期・方法】
楽しみにしていただいていたところ、本当に申し訳ありません。

【スペース名】運営

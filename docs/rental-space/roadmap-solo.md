## 2. フェーズ別ロードマップ

### 2-1. 開業日の根拠

3人版(2027-03-13)より約5週、concept の想定(2026-12-19)より約17週遅い。ずれる理由は「自分の時間」がかかる工程(内見・DIY・搬入・撮影)と、「外部の待ち」(書面承諾・年末年始・審査)が重なるため。

| 区間 | 3人版の想定 | 本書(1人・週10時間) | 理由 |
|---|---|---|---|
| 物件探し(駅決定〜申込) | 10/5〜12/6(9週) | **10/5〜12/20(11週)** | 内見は1件1〜1.5時間+移動。週10時間のうち内見に使えるのは5〜6時間なので**週2〜3件が上限**(同じ駅でまとめる)。10件+再内見で約8週。事業用物件を扱う不動産会社は土日休みのところがあり、平日夜・半休で調整が要る |
| 書面承諾・覚書・契約 | 12/7〜1/22 | **12/21〜2/12(約8週)** | 12/24 までに覚書を送っても、**年末年始(12/26〜1/5ごろ)で約10日止まる**。大家→管理会社→回収業者の書面は2〜3週(1/22 目安)、専門家の確認1週、契約 2/5(金・半休) |
| 入居(鍵渡し) | 2/1 | **2027-03-01(月)** | 契約開始は月初が一般的。2/5 契約からの最短の月初。フリーレント1ヶ月を交渉(RS-144) |
| 内装・調達 | 2/1〜2/21(3週) | **3/1〜3/21(3週)**※購入・発注は 2/13 から | 壁紙→床→照明→家具→家電・AV→防犯の順(procurement 第4章)。**壁紙は1人だと2日**(10〜12時間)かかるため、友人1人の手伝いで1日にする案を推奨(2-3) |
| 撮影・掲載・審査・届出 | 2/20〜3/13 | **3/27 撮影 → 4/3 審査申請(D−14)→ 4/9 使用開始届 → 4/17 開業** | 撮影は内装が終わった次の土曜。審査期間は【未確認】(S-007 で確認)。使用開始届の期限 D−7=4/10 は土曜なので 4/9(金)まで |

- **開業日 4/17 は GW(4/29〜5/5)の直前**。推し活・晩酌とも連休の需要があるので、これより遅れると初月の数字が弱くなる
- **ずれた場合の読み替え**:申込日がずれたら「申込日+10週=入居日、入居日+7週=D」で平行移動する。ただし申込が 12/24 を過ぎると年末年始をまたぎ、さらに約2週遅れる
- **契約後の遅れはお金がかかる**:鍵渡し以降は家賃7万円を含む固定費(約11.5万円/月、costs.md)が発生する。**契約前の準備(レイアウト・購入リスト・手伝いの手配・掲載文)を物件待ちの間に終わらせ、入居から開業までを7週に収める**のが1人版の要
- 必須条件を満たさない物件で急がない(1室しかないので、契約解除は投資の全損に近い。O-16・O-18)。2027-01-31 までに申込できる物件がなければ O-40(条件を緩める順)を決め直す。この場合 D は 2027-06〜07月

- **1人版で一番効くのは「内見のペース」**。ここは自分の時間がそのまま律速になる。週2件を下回る週が2回続いたら、半休で平日内見を入れる

- **4番目はポータル審査**。審査期間は【未確認】(S-007 で確認)。写真と掲載文がそろわないと申請できないので、撮影日が実質の締切
- **準クリティカル**:光回線の開通(契約直後に申込、遅れたらモバイルルーター)、使用開始届(D−7【法定】、平日のみ)、工事計画届(着工7日前【法定】、内装工事がある場合)
- **名前(O-07)は物件と別の経路**:商標確認 → ロゴ → SNS開設(D−35)。10月中に決まれば開業日には影響しない

- **O-06 の推奨案は1人体制に合わない**:decisions-for-owner.md の推奨は「壁紙DIYも開業1〜2ヶ月の清掃も自分で」。本業ありの1人では平日の清掃ができないため、**平日は開業日から委託**に見直す案を S-009・S-010 で決める。決まったら decisions・concept 第6章 #7・operations 1-3 の修正を ai-ceo・ai-admin に依頼する

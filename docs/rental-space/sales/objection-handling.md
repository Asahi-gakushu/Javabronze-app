# 想定反論と切り返し(平日昼・法人/個人事業主向け)

- 作成:ai-sales / 作成日:2026-09-26 / ステータス:下書き(開業前)
- 原則:**ない設備・サービスで切り返さない**。できないことは先に認め、代わりにできることを示すか、合わない相手には無理に勧めない
- 【】は未確定の差し込み欄

## 1. 価格

| # | 反論 | 切り返し | NG |
|---|---|---|---|
| 1 | 「もっと安い会議室がある」 | 「1時間800〜1,000円台の会議室もあります。こちらは6名までの個室に、プロジェクターと撮影用の白壁・照明【導入予定】がついて1,500円/時です。会議だけなら安い会議室が合う場合もあるので、撮影や投影が必要な日にお使いいただく形でも結構です」 | 値下げをその場で約束する(価格調整は月1回・データに基づく方針) |
| 2 | 「毎週使うなら、もっと割り引いて」 | 「月4回以上で10%引きがあります。回数券・定額プランも【案として検討中】で、ご利用頻度をお聞かせいただければ検討材料にします」 | 未承認プランを確定条件として提示する |
| 3 | 「商用撮影で+1,000円は高い」 | 「機材の搬入や壁の消耗分をいただいています。4時間なら撮影半日パック6,800円【商用加算の扱いは要確定】が割安です。一般的な撮影スタジオの相場【◯円/時:要調査】と比べてご判断ください」 | 相場を確認せずに「スタジオより半額」と言う |

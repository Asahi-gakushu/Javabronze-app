# 想定反論と切り返し(推し活・晩酌の個人利用向け)

- 作成:ai-sales / 初版:2026-09-26 / **第3版対応:2026-09-26** / ステータス:下書き(開業前)
- 根拠:`docs/rental-space/strategy/concept.md`(第3版。見出し名で引用)
- 原則:**ない設備・サービスで切り返さない**。できないことは先に認め、代わりにできることを示す。ルール(静音・飲酒時間・ゴミ出し)は**緩めずに理由を説明する**。合わない相手には無理に勧めない
- 使う場面:ポータルの問い合わせ返信、SNSでの質問への返信(返信の公開・送信は社長の確認後)
- 【】は未確定の差し込み欄
- 法人向け(会議・面接・撮影)の反論対応は、法人営業を開業後の P4 に回すため**本版から外した**。P4 開始時に作り直す

## 営業記録のお願い

- 「22:30の飲酒終了」「コール不可」「ゴミ出し」「早朝承認制」「モニター・プレーヤーがない」に関する反論は、件数を記録して ai-analyst と ai-ceo に渡す(ルールと投資の見直し材料。**ルール自体は ai-ceo の判断なしに変えない**)
- 決まったことは ai-secretary が `docs/tasks.md` と議事録に残す

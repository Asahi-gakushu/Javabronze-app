- 前提資料:`docs/rental-space/strategy/concept.md`(第3版。見出し名で引用)、`docs/rental-space/research/market-report.md`
- 第3版での方針変更:
  - **開業前は、推し活コミュニティと晩酌グループへの個人向けの訴求に絞る**(concept.md「事業コンセプト」主軸A・B)
  - **法人営業(会議・面接・研修・撮影)は副次扱いのため、開業後の P4 に回す**(concept.md「各部署への指示」ai-sales)。初版の「法人・定期利用 月8件」の目標は取り下げる
- 目的:稼働率(月510時間が分母)3ヶ月20% → 6ヶ月30% → 12ヶ月40%、平均単価2,700円/時(concept.md「1年回収に必要な数字」)。営業としては**平日夜と土日祝の高単価枠を晩酌・推し活で埋め、平日昼は「平日休みの人の推し活・昼飲み」で埋める**

## 0. 営業の前に守ること

1. **物件・設備は未確定**。設備(プロジェクター・スクリーン・サウンドバー・Wi-Fi・ソファ等)は「導入予定」として話す。開業して写真で確認できるまで「ある」と断言しない
2. **飲酒と6:00〜23:00の営業は、物件契約の書面承諾が前提**。物件が決まるまでは「飲酒可の予定」と言う
3. **ない設備・サービスは売らない**:お酒・飲食の販売/提供、火を使う調理、モニター、ホワイトボード、撮影機材の貸し出し、カラオケ・コール、深夜・宿泊・仮眠、スタッフ常駐、完全防音
4. **ハウスルールを先に見せる**(22:00静音、22:30飲酒終了、早朝は飲酒不可、泥酔者入室不可、ゴミは自分で24時間ゴミ置き場へ)。ルールが合わない人には勧めない。それが騒音トラブルと契約解除を防ぐ
5. 外部への送信・DM・SNS投稿・掲載・チラシ設置は、**すべて社長の確認を取ってから**行う
6. スペース名は【第1候補「推しと晩酌」。商標確認後に社長が決定】。決定前に名前入りの資料を外に出さない

差し込み欄(共通):最寄り駅【駅名・徒歩◯分(8分以内)】/ 広さ【◯㎡】/ 定員【6名(10㎡なら4名)】/ 開業日【◯年◯月◯日】/ 掲載ポータル【2社】

## 2. セグメント別の課題・訴求点・アプローチ

### 2-1. 推し活コミュニティ

| 項目 | 内容 |
|---|---|
| よくある課題 | カラオケの部屋は画面が小さく、飾り付けしにくい/自宅では人数と音が気になる/生誕祭の飾り付けと写真映えする場所がほしい/配信ライブをみんなで大画面で観たい |
| 訴求点 | 80〜100インチの大画面(予定)/有孔ボードの装飾壁・ピクチャーレールで飾れる(予定)/6人まで貸切/無人で人目を気にしない/推し活5時間パック15,800円(6人で1人約2,630円)/持ち込みで晩酌もできる(11:00〜22:30) |
| 先に伝えること | コール・合唱・手拍子は不可、音量上限あり、22:00から静音タイム。BD/DVDプレーヤーは【有無未定】。ゴミは自分で24時間ゴミ置き場へ |
| 言ってはいけないこと | 「ライブハウス並みの音響」「騒いでOK」「プレーヤーあり(未確定)」 |
| アプローチ(開業前) | ①掲載文と写真の主役を「上映会・生誕祭」に(ai-writer・ai-designer)②X・Instagramで「#生誕祭 #上映会 #推し活部屋」向けの投稿(社長承認後、ai-marketer の計画に沿う)③オープニング1ヶ月目(25%引き)を生誕祭の予約につなげる |

### 2-2. 晩酌グループ(家飲みの代わり)

| 項目 | 内容 |
|---|---|
| よくある課題 | 家が狭い・家族がいて人を呼べない/居酒屋は1人4,000〜5,000円かかり、長居しにくく、騒がしい【相場は ai-marketer 確認】/好きなお酒とつまみを持ち寄りたい |
| 訴求点 | 晩酌3時間パック7,800円(4人で1人1,950円)/持ち込み・デリバリー可/冷蔵庫・電子レンジ・電気ケトル(予定)/新品のグラス・食器/大画面で動画やスポーツを観ながら飲める/仕事帰りに寄れる駅(駅徒歩8分以内) |
| 先に伝えること | お酒の販売・提供なし、火を使う調理不可、全館禁煙、20歳以上の予約者、泥酔者は入室不可、22:30飲酒終了・22:45までにゴミ出し・23:00退室 |
| 言ってはいけないこと | 「飲み放題」「パーティー向け」「大人数OK」「二次会・朝まで」 |
| アプローチ(開業前) | ①ポータルの「飲み会/パーティー」ではなく「家飲み・女子会・少人数」カテゴリを中心に掲載(ai-marketer と調整)②SNSで「家に呼べない晩酌」を切り口に発信(社長承認後)③利用後のレビュー依頼で「静かで落ち着く」評価を集める |

### 2-3. 平日休みの推し活・昼飲み層

| 項目 | 内容 |
|---|---|
| よくある課題 | 友達の休みと合わず、平日の昼に集まることが多い/昼から飲める静かな場所が少ない |
| 訴求点 | 平日昼1,500円/時、昼飲み・推し活4時間パック5,800円(4人で1人1,450円)/飲酒は11:00から |
| アプローチ | 掲載文に「平日休みの方へ」の一文と平日昼パックを載せる。SNSで平日の空き枠を案内(社長承認後) |

### 2-4. 早朝(遠征の朝の身支度・朝の観戦)

- 営業はしない。掲載文とFAQ(早朝は承認制・前々日まで・飲酒不可)で案内するだけ
- 朝の3時間パック3,000円。稼働率の目標は10%と低め(concept.md「早朝枠と清掃の回し方」)

## 3. 営業の進め方

| 時期 | やること | 担当 |
|---|---|---|
| 開業前(P0〜P2) | FAQ・反論対応・個人向け案内を確定値で更新(【】を埋める)。ハウスルールと矛盾がないか ai-writer と突き合わせ。SNS発信の文面案を ai-marketer・ai-writer と用意 | ai-sales / ai-writer / ai-marketer |
| 開業〜3ヶ月(P3) | 推し活・晩酌の問い合わせ内容と反論を記録。レビューを集める。ルールへの不満を集計して ai-ceo へ | ai-sales / ai-analyst |
| **P4(開業後)** | **法人・個人事業主向け営業を開始するか判断**(平日昼の稼働率を見て ai-ceo が判断)。開始する場合は、proposal.md の付録を第3版の設備(モニター・ホワイトボード・撮影機材なし)で作り直し、会議系ポータルの結果も見る | ai-ceo → ai-sales |
| 毎月 | 時間帯別(早朝・平日昼・平日夜・土日祝)の稼働率とセグメント別件数を確認 | ai-analyst |

## 4. 要望(ai-ceo 判断 / ai-secretary タスク化)

1. BD/DVDプレーヤーを置くか(円盤鑑賞会の需要。新品必須のAV機器の予算内に入るか)
2. 20歳未満の同席を認めるか(規約で定義。推し活コミュニティには10代もいる)
3. 装飾用テープの使用可否(U-07、生誕祭の飾り付けに直結)
4. 定期利用の割引・回数券(U-13)を個人向けに設けるか
5. P4 で法人営業を始める条件(平日昼の稼働率の基準)を決める

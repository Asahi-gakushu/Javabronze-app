# 平日昼(8〜17時)向け 顧客セグメントとアプローチ

- 作成:ai-sales / 作成日:2026-09-26 / ステータス:下書き(開業前)
- 前提資料:`docs/rental-space/strategy/concept.md`、`docs/rental-space/research/market-report.md`
- 目的:平日昼の稼働率15%(6ヶ月)と、法人・定期利用の月8件(12ヶ月)を達成する(concept.md 3-2)

## 0. 営業の前に守ること

1. **物件・設備は未確定**。コンセプト上の設備(プロジェクター、白壁の撮影面、撮影照明、Wi-Fi、会議/シアター配置の家具)は「導入予定」として話す。開業して写真で確認できるまでは「ある」と断言しない
2. **ない設備・サービスは売らない**。飲食の提供、宿泊・仮眠、深夜利用、本格防音、ダンス/楽器向けの床と防音、受付スタッフの常駐はない
3. **直接契約(ポータル外の請求書払い・定額)は「案」**。ポータル規約で直接取引への誘導が禁止されている場合がある(market-report 第2章)。規約確認と社長承認が済むまで、正式な申込は受けない
4. 外部への送信・営業訪問・DM・掲載は、すべて社長の確認を取ってから行う

差し込み欄(共通):最寄り駅【駅名・徒歩◯分】/ 広さ【◯㎡】/ 定員【6名(10㎡なら4名)】/ 開業日【◯年◯月◯日】/ 掲載ポータル【スペースマーケット・インスタベース+平日向け1社】

## 1. セグメント一覧(優先順位つき)

| 優先 | セグメント | 想定利用 | 相性 | 理由 |
|---|---|---|---|---|
| A | 個人クリエイター・小規模EC事業者(物撮り・SNS撮影・動画収録) | 週1〜月数回、2〜4時間 | ◎ | 白壁の撮影面・照明はコンセプトの差別化点。撮影半日パック(4時間6,800円)が既にある |
| A | 採用面接・オンライン面接(中小企業、人材紹介会社、個人の転職者) | 平日昼に1〜3時間 | ◎ | 1時間から使える。静かな個室であること自体が価値 |
| B | 小規模研修・勉強会・少人数会議(近隣の中小企業、士業、スタートアップ) | 2〜4時間、月1〜4回 | ○ | 6名以内の会議・研修。プロジェクターでスライド投影が可能(予定) |
| B | 個人講師のレッスン(ヨガ・ストレッチ・コーチング・語学・占いなど) | 週1回の定期枠 | △〜○ | 定期利用と相性がよいが、ヨガは広さ・床・天井高の確認が必要。**ダンス・楽器レッスンは対象外**(concept.md 1-4) |

## 2. セグメント別の課題・訴求点・アプローチ

### 2-1. 個人クリエイター・小規模EC(撮影)

| 項目 | 内容 |
|---|---|
| よくある課題 | 自宅だと生活感が写り込む/白背景と照明を毎回組むのが面倒/本格スタジオは1時間5,000円以上で割高【相場は要確認】/短時間だけ借りたい |
| 訴求点 | 白壁の撮影面+撮影照明(導入予定)/平日昼1,500円/時から(商用撮影は+1,000円/時)/4時間の撮影半日パック6,800円/無人運営なので人目を気にせず撮れる/装飾壁で世界観づくりも可能(予定) |
| 言ってはいけないこと | 「プロ仕様のスタジオ」「ホリゾント完備」「機材貸出あり」(いずれも未定・計画なし)。カメラ・三脚・背景紙の貸出は【有無未定】 |
| アプローチ | ①ポータルの「撮影」カテゴリ掲載と、白壁・照明の作例写真 ②Instagram/X でハッシュタグ(#物撮り #ハンドメイド作家 など)の投稿者へ、ポータルページの案内(DMは社長承認後) ③近隣の専門学校・ハンドメイドイベントへのチラシ設置依頼【設置先は要調査】 |
| 定期化の提案 | 回数券(案)/月4回以上で10%引き |

### 2-2. 採用面接・オンライン面接

| 項目 | 内容 |
|---|---|
| よくある課題 | 自社に面接室がない(シェアオフィス・小規模事業者)/カフェでは情報管理と騒音が不安/候補者の最寄りに近い場所で面接したい/転職者本人はオンライン面接の静かな場所がない |
| 訴求点 | 駅徒歩5分以内(物件条件)/1時間から予約可能/個室で第三者が入らない/Wi-Fi(導入予定。回線速度は開業後に実測値を掲載【◯Mbps】)/スマートロックで受付不要 |
| 注意点 | 防音室ではない。隣室・廊下の音が【完全には遮断できない】ことを先に伝える。受付スタッフはいないので、候補者の案内は利用者側で行う(暗証番号の共有方法を案内) |
| アプローチ | ①近隣の人材紹介会社・派遣会社への1枚提案書(proposal.md)②スペイシー等の会議系ポータル掲載(concept.md 5-9)③商工会議所・コワーキングの掲示板【要調査】 |
| 定期化の提案 | 平日昼定額プラン(案)/回数券(案) |

### 2-3. 小規模研修・勉強会・少人数会議

| 項目 | 内容 |
|---|---|
| よくある課題 | 貸会議室は10名以上の部屋が多く、少人数だと割高/社内だと電話や来客で集中できない/スライドを映せる場所がほしい |
| 訴求点 | 6名まで(10㎡の場合は4名)/100インチ以上のプロジェクター(導入予定)/会議配置のテーブル/8時から使える(朝研修)/平日昼1,500円/時 |
| 注意点 | ホワイトボード・モニター・ウェブ会議用スピーカーマイクは【有無未定】。飲食は持ち込みのみ(運営者は提供しない)。7名以上は不可 |
| アプローチ | ①近隣の中小企業・士業事務所・学習塾へのポスティングまたは訪問(社長承認後)②会議系ポータル ③既存利用者へのリピート案内(ポータル内メッセージの範囲で) |
| 定期化の提案 | 月4回以上で10%引き/平日昼定額プラン(案) |

### 2-4. 個人講師のレッスン(ヨガ・ストレッチ・コーチング・語学など)

| 項目 | 内容 |
|---|---|
| よくある課題 | 公共施設は抽選・予約が取りにくい/スタジオを月額で借りるほどの生徒数がいない/毎週同じ時間に同じ場所を確保したい |
| 訴求点 | 毎週同じ枠を確保しやすい平日昼/1〜3名の少人数レッスン向き/1時間1,500円から/定期利用割引 |
| 注意点 | **ヨガは条件つき**:15㎡で家具を寄せた場合にマットが【◯枚】敷けるか、床材(クッション性・防音)、天井高、下の階への振動を、物件決定後に確認するまで「ヨガOK」と打ち出さない。ヨガマットの貸出は【有無未定】。更衣室・シャワーはない【物件次第】。ダンス・楽器・大声を出すレッスンは不可 |
| アプローチ | ①ポータルの「レッスン」カテゴリ(物件確定後、可能な種目のみ記載)②地域の講師向けSNSコミュニティ・ストアカ等の講師【要調査】③体験利用の初回割引(オープニング価格の範囲で) |
| 定期化の提案 | 毎週固定枠の平日昼定額プラン(案) |

### 2-5. テレワーク・個人作業(補助)

- 営業はしない。直前割(稼働率10%未満の枠に設定、concept.md 2-3)で空き枠を埋める用途
- 注意:料金を下げすぎると平日昼の単価目標を崩すため、直前割は ai-analyst の数字を見て月1回だけ調整

## 3. 営業の進め方(開業前〜開業6ヶ月)

| 時期 | やること | 担当 |
|---|---|---|
| 開業前 | 本資料・提案書・FAQを確定値で更新(【】を埋める)。ポータル規約の直接取引条項を確認 | ai-sales / ai-researcher |
| 開業〜3ヶ月 | 作例写真(撮影・会議・面接配置)をポータルに掲載。平日昼の問い合わせ内容を記録 | ai-writer / ai-designer / ai-sales |
| 4〜6ヶ月(P4) | 近隣の人材会社・中小企業・講師へ提案書で営業(社長承認後)。定期利用の試行 | ai-sales |
| 毎月 | 平日昼の稼働率・セグメント別件数を確認し、優先順位を見直す | ai-analyst |

## 4. 要望(ai-ceo 判断 / ai-secretary タスク化)

1. 回数券・平日昼定額プラン(案)を採用するか、ポータル経由と直接契約のどちらで提供するか(proposal.md 参照)
2. 撮影用の小物(背景紙・三脚・レフ板)の貸出を設けるか。撮影セグメントの成約率に影響
3. 会議・面接用のモニター/ホワイトボード/スピーカーマイクを設備に入れるか
4. インボイス登録の判断(法人利用が増える前提なら必要。concept.md 5-4)
5. ヨガ等のレッスン利用を認めるか(物件の床・下階の条件確認後)

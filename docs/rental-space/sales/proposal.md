# 推しと飲める、6人までの小さな部屋

**【スペース名(第1候補「推しと晩酌」)】** ――【駅名】駅 徒歩【◯】分 / 6名まで / 入室6:00〜退室23:00

## こんなときに

- **推し活**:生誕祭、上映会、配信ライブの同時視聴、円盤の鑑賞会、グッズの交換会
- **晩酌**:家に呼べないけど、家飲みみたいにゆっくり飲みたい(2〜6人、持ち込み・デリバリー)
- **推しを見ながら晩酌**:大画面で推しを観ながら、好きなお酒とつまみで
- **遠征の朝**:ライブ当日の身支度・着替え・荷物の整理(早朝枠、飲酒不可)

## お部屋(【開業後に実物写真と確定値へ差し替え】)

- 大画面(80〜100インチ)のプロジェクターとスクリーン。HDMIでつないで観られます
- 音量上限つきのサウンドバー、Wi-Fi(実測【◯】Mbps)
- 合皮ソファ(2人掛け×2)とスツール2で6席、ローテーブル
- 飾り付けに使える有孔ボードの装飾壁とピクチャーレール、全身鏡

## 社内メモ(案内には載せない)

- 対象は**幹事**(生誕祭の主催者、上映会・晩酌の言い出し役)。1人あたりの金額で見せると、居酒屋・カラオケと比べてもらいやすい
- 「騒げる」「パーティー向け」と受け取られる表現は使わない。ルールを先に見せ、合わない人には勧めない(騒音と契約解除のリスクを下げるため)
- 平日昼は「平日休みの方へ」の一文で案内する。平日夜・土日祝の高単価枠を値引きで埋めない(価格の見直しは月1回、手取り単価で判断)
- 1予約の平均は4時間で計算している。短い予約が増えると清掃費(1回1,500円目標)の負担が重くなるので、パック中心に案内する

## P4 に回した法人向け提案書(開業前は使わない)

- 初版の法人・個人事業主向け提案書(平日昼の会議・面接・撮影、回数券・定額プラン案)は**使用停止**。営業時間・料金・設備が第3版と合わない(8時開始、モニター・撮影照明・会議用テーブルの記載、平日昼17時以降2,500円など)

# 内見チェックリスト(第3版対応)

- 作成:ai-admin / 作成日:2026-09-26
- 前提:`strategy/concept.md` 第3版(1-6 物件の選び方、1-7 ゴミの扱い、1-5 ハウスルール、3-2 数値目標、第8章 ai-admin への指示)
- 使い方:1物件につき1枚コピーして使う(非公開のメモやスプレッドシートに転記)。**担当者の氏名・電話番号・住所の番地など個人情報や、物件を特定できる情報はこのリポジトリに書かない**
- 目安:P1 で**10件以上**内見する(安い物件は書面をもらいにくいため)

> **注意:本書は法的助言ではありません。** 契約条項の有効性・解釈、ゴミの区分(事業系ゴミかどうか)、消防・建築の条件は、契約前に専門家(弁護士・宅地建物取引業者・自治体・消防署など)で確認してください。大家・管理会社への問い合わせ、申込、交渉、契約はすべて社長が行います。

---

## 0. 判定のしかた

- **必須(A)**:1つでも「×」か「書面で確認できない」なら見送る(concept.md 1-6 の必須条件8つ)
- **確認(B)**:「×」でも即見送りではないが、費用・運用・リスクとして記録する
- **加点(C)**:同じ条件の物件を比べるときに使う
- 口頭の回答は「△(口頭のみ)」と書き、**契約前に書面(契約書・特約・覚書・管理規約)で「○」にする**。△のまま契約しない

## 2. ゴミ置き場の確認5項目(必須条件 A3 の中身)

concept.md 1-7 の「契約の前に書面で確認すること」。**5項目すべてが書面で○にならなければ A3 は×**。家庭ゴミの集積所しかない物件は見送る。

| # | 確認項目 | 聞き方の例(社長が問い合わせる) | 回答 | 書面 |
|---|---|---|---|---|
| G1 | **時間貸しの利用者**(契約者本人ではない第三者)がゴミ置き場を使ってよいか | 「レンタルスペースの利用者が、退室時に自分でゴミ置き場へゴミを出してもよいですか」 | ○ / △ / × | 有 / 無 |
| G2 | **24時間**出せるか(6:00〜22:45 に出せれば最低限可。施錠・扉の開閉時間の有無) | 「早朝6時台と夜22時台にも出せますか。施錠される時間はありますか。鍵や暗証番号は必要ですか」 | ○ / △ / × | 有 / 無 |
| G3 | **分別の区分**(燃やすゴミ・缶・瓶・ペットボトルを出せるか。段ボールの扱い) | 「缶・瓶・ペットボトルは出せますか。分別区分の掲示はありますか」 | ○ / △ / × | 有 / 無 |
| G4 | **費用**(ビルの事業系ゴミ処理費が月いくらか。量による追加料金) | 「事業系ゴミの処理費は月いくらですか。量による追加はありますか」 ※計画は月5,000円(costs.md 第2章) | 月◯円 | 有 / 無 |
| G5 | **ゴミ置き場までの動線**(住戸や他のテナントの前を通らずに行けるか) | 実際に部屋からゴミ置き場まで歩く。所要時間、エレベーターの要否、他テナントの出入口の前を通るか | ○ / △ / × | —(写真で記録) |

**内見時にあわせて見ること**

- [ ] ゴミ置き場の写真(扉・掲示・分別表示)を撮る(入室案内の道順写真の下見。人や他社の情報が写らないように)
- [ ] ゴミ置き場の清潔さ・カラス対策・溢れていないか(他テナントとのトラブルの芽)
- [ ] 部屋からゴミ置き場まで片道何分か(22:30〜22:45 の15分で片付け+ゴミ出しが終わるか)
- [ ] 利用者のゴミが「事業系ゴミ」になるか、地域の家庭ゴミ集積所に出せないことの確認【要確認:ai-researcher・自治体】

## 3. 騒音・近隣の条件(B)

晩酌を認めるので、騒音は契約解除に直結する(concept.md 1-5・第9章)。

| # | 確認事項 | 見るポイント | 判定 |
|---|---|---|---|
| B1 | 隣室・上下階のテナントの業種と営業時間 | 夜に静かな業種(クリニック・士業事務所・学習塾など)が隣や上下にあると、22時台の音で苦情になりやすい。飲食店・物販なら相性が良い | ○ / △ / × |
| B2 | 壁・床・窓・ドアの遮音 | 隣室や廊下の音が聞こえるか。スマホで音楽を流して廊下で聞く(1人が室内・1人が廊下)。ドアの下の隙間 | ○ / △ / × |
| B3 | 建物の外への音漏れ | 窓の位置(道路・隣の住宅に面していないか)。**1階の路面・地下は避ける** | ○ / △ / × |
| B4 | 近隣の建物 | 窓の向かい・裏手に住宅やマンションがないか(建物内に住戸がなくても、隣の住宅から苦情が来る) | ○ / △ / × |
| B5 | 管理規約の騒音・飲酒・共用部の規定 | 使用細則に「音量」「飲酒」「共用部で騒がない」「夜間の出入り」の定めがあるか。ハウスルール(22時から静音・22:30飲酒終了・23時退室)と矛盾しないか | ○ / △ / × |
| B6 | 過去の苦情・トラブル | 管理会社に「前の入居者やほかのテナントで騒音の苦情がありましたか」と聞く | ○ / △ / × |
| B7 | 騒音センサー・入口カメラの設置 | 室内の騒音センサー、入口付近のカメラを設置してよいか(共用部を映さない位置) | ○ / △ / × |
| B8 | 建物の入口・エントランス | 建物の前で利用者がたまりやすい構造か。夜間の人通り・照明 | ○ / △ / × |

## 7. 内見の持ち物と記録

- メジャー(5m)、スマートフォン(写真・騒音計アプリ・スピーカー代わり)、このチェックリスト、筆記用具
- 写真:部屋全体・窓の外・ドア・コンセント・分電盤・ゴミ置き場と道順・エントランス(他の人が写らないように)
- 記録は非公開のスプレッドシートに「物件ID(番号のみ)・内見日・A1〜A8・G1〜G5・B・C・総合判定」で残す。比較表の匿名化した要約だけを ai-secretary が議事録に載せる

## 8. 内見後の流れ

1. A1〜A8 がすべて ○ か △ の物件だけを候補に残す(× が1つでもあれば見送り)
2. △ の項目を、社長が管理会社に**書面での回答**を依頼する(送信は社長が行う)
3. 書面で ○ がそろったら contract-notes.md の覚書文例(第1〜7条)を専門家に確認してもらい、交渉に入る
4. 契約の判断は社長(concept.md 第6章 #9:必須条件8つの書面がそろわなければ契約しない)

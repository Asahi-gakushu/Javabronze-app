# レンタルスペース 開業手続きチェックリスト(第3版対応)

- 作成:ai-admin / 初版:2026-09-26 / 第3版対応:2026-09-26
- 前提資料:`docs/rental-space/research/market-report.md`(第4章 法規制)、`docs/rental-space/strategy/concept.md` 第3版(「物件の選び方」1-6、「ゴミの扱い」1-7、「初期投資110万円の内訳」第4章、「立ち上げロードマップ」第5章、「社長が決めなければならないこと」第6章)
- 第3版の前提:**初期投資110万円+運転資金70万円=180万円**、営業は**入室6:00〜退室23:00**、飲酒可(持ち込みのみ)、物件の**必須条件8つ**、覚書は**全7条**(contract-notes.md)、家具は**中古中心**(procurement.md)、清掃は**1回1,500円**が目標(costs.md 3-1 の C1〜C5)
- 時系列は concept.md のフェーズ(P0 第0〜2週 / P1 第2〜8週 / P2 第8〜12週 / P3 開業後)に合わせた。**開業日を「D」とし、期限は D からの逆算で書く**
- 担当:**社長**=署名・申込・支払い・提出・外部との連絡(外部送信・課金・契約は必ず社長)。**AI社員**=下調べ・書類の下書き・期限管理
- 期限の根拠の区分:【法定】法令・行政の定め(ただし本文は一次情報で要確認)/【推奨】運営上の目安
- 本書は手続きの抜け漏れを防ぐための管理表で、法的助言・税務助言ではない。届出の要否や期限は、所轄の消防署・保健所・税務署・都税事務所(県税事務所)に確認すること

---

## 使い方

1. 開業日 D が決まったら、下表の「期限」を実際の日付に書き換え、ai-secretary が `docs/tasks.md` に転記する
2. 完了したら `[ ]` を `[x]` にし、完了日と控えの保管場所(紙/クラウドのフォルダ名)を備考に書く
3. 控え・書類の現物(契約書・届出の控え・保険証券)は**このリポジトリに置かない**(個人情報・契約情報を含むため)。保管場所の名前だけを書く

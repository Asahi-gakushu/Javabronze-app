# 契約で確認すべき条項リスト(賃貸借契約・清掃委託契約)(初版)

- 作成:ai-admin / 作成日:2026-09-26
- 前提:market-report.md 第4章(法規制)・第6章(失敗例)、concept.md 1-5(物件の必須条件)

> **注意:本書は法的助言ではありません。** 契約書を読むときに見落としやすい論点を並べたチェックリストです。条項の有効性や解釈、交渉の進め方は、契約前に弁護士・司法書士などの専門家、または宅地建物取引業者の説明で確認してください。契約の締結・署名・交渉は社長が行います。

## 1. 内見・申込前のチェック(契約書を見る前に)

| # | 確認事項 | 判定 |
|---|---|---|
| 1 | 事業用(店舗・事務所)の物件か。住居用・住宅専用の管理規約ではないか | 必須 |
| 2 | 家賃(共益費込み)12万円/月以下か | 必須 |
| 3 | 駅徒歩5分以内か | 必須 |
| 4 | 同じフロアと上下階に住戸がないか | 必須 |
| 5 | 貸主が「レンタルスペースとしての時間貸し」を書面で承諾する見込みがあるか | 必須 |
| 6 | 壁・床・窓の遮音性(隣室・廊下に音が漏れるか)、共用部の広さ(待ち合わせで騒がしくならないか) | 確認 |
| 7 | 電源(コンセントの数・契約アンペア)、空調、光回線の引き込み | 確認 |
| 8 | 夜間の出入り、エレベーター、看板・案内表示の可否 | 確認 |
| 9 | 搬入経路(家具・プロジェクター) | 確認 |
| 10 | 解約予告期間(3か月以内が望ましい) | 確認 |
| 11 | ゴミの出し方(事業系ゴミの扱い) | 確認 |

## 2. 賃貸借契約で確認すべき条項

### 2-1. 最重要(ここが満たせなければ契約しない)

| # | 条項・論点 | 確認すること | リスク・背景 |
|---|---|---|---|
| 1 | **転貸・第三者使用の承諾** | 「賃借人がレンタルスペース(時間単位の貸室)として第三者に利用させること」を承諾する旨が、特約か覚書で**書面に**あるか。ポータル(スペースマーケット等)への掲載も含むか | 民法612条:承諾のない転貸は契約解除の理由になりうる(market-report.md 第4章)。口頭の承諾は後で争いになる |
| 2 | **使用目的(用途)** | 使用目的が「事務所」だけになっていないか。「レンタルスペース(会議・撮影・少人数のパーティー等の時間貸し)」と具体的に書かれているか | 用途違反は解除の理由になりうる |
| 3 | **営業時間・利用時間の制限** | 8:00〜23:00の営業が認められるか。建物の夜間閉鎖・セキュリティの時間 | 建物ルールと食い違うと苦情・違反になる |
| 4 | **定員・騒音・飲酒の制限** | 利用人数、パーティー・飲酒の可否、音量の制限が定められていないか。あるならハウスルール(定員6名・22時退室・音量上限)と合っているか | 騒音苦情が閉店の主な原因(market-report.md 第6章) |
| 5 | **解除条項** | 貸主がどんな場合に催告なしで解除できるか(苦情、近隣迷惑、規約違反)。「苦情1回で解除」のような広すぎる条項がないか | 1室しかないため、解除=投資の全損に近い |

**覚書の文例(たたき台。専門家の確認前提)**

```
覚書

賃貸人〇〇(以下「甲」)と賃借人〇〇(以下「乙」)は、令和〇年〇月〇日付け建物賃貸借契約(以下「原契約」)に関し、次のとおり合意する。

第1条 甲は、乙が本物件を時間単位の貸室(いわゆるレンタルスペース)として、会議・撮影・少人数の集まり等の用途で第三者に利用させること、及びそのために乙がインターネット上の予約サービスに本物件を掲載することを承諾する。
第2条 前条の利用時間は午前8時から午後11時までとし、宿泊の用には供しない。
第3条 甲は、乙が本物件にスマートロック、防犯カメラ(入口付近)及び騒音センサーを設置すること並びに別紙の内装工事を行うことを承諾する。原状回復の範囲は別紙のとおりとする。
第4条 乙は、利用者に対し定員・利用時間・騒音・ゴミ等に関する利用規約を守らせ、近隣からの苦情があった場合は速やかに対応する。
第5条 本覚書に定めのない事項は原契約による。
```

### 2-2. お金に関する条項

| # | 条項・論点 | 確認すること |
|---|---|---|
| 6 | 賃料・共益費・改定 | 賃料の改定(増額)条項、自動増額の有無。家賃1万円増で損益分岐の稼働率が約1.7ポイント悪化 |
| 7 | 敷金・保証金の償却(敷引き) | 退去時に差し引かれる割合・金額。何が返ってくるのか |
| 8 | 礼金・更新料・更新事務手数料 | 金額と支払時期(costs.md 1-1 に記入) |
| 9 | 保証会社・連帯保証人 | 保証会社の加入必須か、保証料(初回・毎年) |
| 10 | フリーレント | 内装工事期間の賃料免除を交渉できるか(開業までの固定費を減らす) |
| 11 | 賃料の支払日・遅延損害金 | 支払日とポータルの入金日(翌月末等)のずれ |
| 12 | 消費税 | 事業用物件の賃料は消費税がかかる。表示が税込か税抜か |

### 2-3. 内装・設備・原状回復

| # | 条項・論点 | 確認すること |
|---|---|---|
| 13 | 内装工事の承諾 | 事前承諾の方法(書面)、指定業者の有無、工事時間の制限 |
| 14 | **原状回復の範囲** | 事業用物件は「スケルトン戻し」など範囲が広いことがある。装飾壁(有孔ボード・ピンレール)、照明、ビス穴、壁紙の張り替えを誰が負担するか。入居時の写真を残す |
| 15 | 鍵の交換・スマートロック設置 | 鍵交換・後付けの可否、合鍵の扱い、退去時の復旧 |
| 16 | 防犯カメラの設置 | 設置場所(室内か入口か)、共用部を映すことの可否 |
| 17 | 設備の修繕負担 | 空調・給湯・照明など既存設備の故障時、貸主と借主どちらが直すか |
| 18 | 電気容量の増設 | 増設の可否と費用負担 |
| 19 | 看板・表示 | 郵便受け・ドアへの表示、案内看板の可否 |

### 2-4. 期間・解約・その他

| # | 条項・論点 | 確認すること |
|---|---|---|
| 20 | 契約の種類 | 普通借家か定期借家か。定期借家なら期間満了で終わり、再契約できるとは限らない |
| 21 | **中途解約の予告期間** | 3か月以内が望ましい(撤退時の損失を抑える)。6か月以上の場合は撤退判断をその分早める |
| 22 | 違約金 | 短期解約違約金(1年未満解約で賃料○か月分など)の有無 |
| 23 | 反社会的勢力の排除 | 利用者が反社会的勢力だった場合の扱い。ポータル側の審査との関係 |
| 24 | 近隣・管理規約の遵守 | 建物の使用細則(ゴミ出し、共用部の利用、搬入時間)を受け取っているか |
| 25 | 保険加入の義務 | 火災保険(借家人賠償)の指定・補償額の条件 |
| 26 | 損害賠償・免責 | 利用者が起こした事故(水漏れ・火災・共用部の破損)の責任を借主が負う範囲。施設賠償責任保険でカバーできるか |
| 27 | 通知・連絡先 | 苦情・緊急時の連絡経路(管理会社の夜間窓口) |
| 28 | 名義 | 個人名義か法人名義か。後で法人化したときに名義変更できるか |

## 3. 清掃委託契約で確認すべき条項

| # | 条項・論点 | 確認すること |
|---|---|---|
| 1 | 業務範囲 | operations.md 1-2 のチェックリスト(ゴミ回収・拭き掃除・備品補充・家具の配置戻し・写真報告)をすべて含むか。月1回の深い清掃は別料金か |
| 2 | 料金と単価 | 1回あたりの料金(試算2,000円/回)、交通費、深夜・早朝・休日の割増、最低発注回数・月額固定の有無 |
| 3 | 対応時間とバッファ | 退室後30分以内に完了できるか。連続予約のときに対応できるか。対応できない時間帯 |
| 4 | 依頼・キャンセルの方法 | 通知手段(カレンダー招待・メール)、依頼の締切、直前キャンセル時の料金 |
| 5 | 報告の方法 | 清掃前後の写真、破損・忘れ物・ルール違反の報告(Googleフォーム等)、報告の期限 |
| 6 | 消耗品 | 補充する消耗品を誰が購入・負担するか |
| 7 | 鍵の管理 | 清掃担当用の暗証番号の発行方法、他人への共有禁止、契約終了時の無効化 |
| 8 | 損害賠償・保険 | 清掃中の破損・事故の責任、委託先の賠償責任保険の加入有無 |
| 9 | 再委託 | 別の人に再委託してよいか。再委託先の管理 |
| 10 | 秘密保持・個人情報 | ゲスト情報・暗証番号・室内の写真の取り扱い、SNS等への投稿禁止 |
| 11 | 品質基準と改善 | 清掃不備でゲストから苦情が来た場合の再清掃・減額 |
| 12 | 契約期間・解約 | 解約予告期間、撤退時にすぐ終了できるか |
| 13 | 支払い条件 | 締め日・支払日、請求書の形式(インボイス番号の有無) |
| 14 | 契約形態 | 業務委託(請負・準委任)であること。個人に委託する場合、源泉徴収の要否は業務内容で異なる【要確認:税理士】 |

## 4. ポータル利用規約で確認すること(参考)

| # | 論点 | 確認すること |
|---|---|---|
| 1 | 手数料 | 現行の料率(market-report.md 第7章の要再確認リスト) |
| 2 | 直接取引への誘導 | 自社サイト・直接予約への誘導が禁止されていないか(禁止なら直接予約を計画に入れない) |
| 3 | キャンセル・返金 | キャンセルポリシーの設定範囲、トラブル時の返金ルール |
| 4 | 補償 | ポータル保険の対象・上限・申請期限・申請者 |
| 5 | メッセージ | ゲストとの連絡をポータル内に限る規定の有無 |
| 6 | 入金 | 締め日・振込日・振込手数料 |

## 5. 契約前の最終確認(社長用)

- [ ] 2-1 の最重要5項目がすべて書面で確認できた
- [ ] 原状回復の範囲と、退去時に戻る保証金の額を把握した
- [ ] 解約予告期間を撤退基準(concept.md 3-3)の判断時期に反映した
- [ ] 物件取得費の合計が150万円以内に収まる
- [ ] 不明な条項を専門家に確認した(確認した日と相手を非公開の記録に残す)

## 6. 経費・帳簿の記録ルール

### 6-1. 基本

1. **事業用の口座とカードを分ける**。事業の支払い・入金はすべて事業用で行う。やむを得ず私用カードで払ったら、同じ月のうちに経費台帳に記録する
2. **証憑(領収書・請求書・レシート・明細)をすべて保存**する。紙はスキャンまたは撮影して、月別フォルダ(例:`経費/2026-10/`)に「日付_支払先_金額」のファイル名で保存。保管場所は非公開のクラウドにし、リポジトリには置かない
3. **電子で受け取ったもの(メールの請求書、ポータルの売上明細PDF、ネット購入の領収書)は電子のまま保存**する。電子帳簿保存法で、電子取引のデータは電子で保存することが求められている。日付・金額・取引先で検索できるようにファイル名をそろえる
4. 帳簿は会計ソフトまたは第4章のCSV台帳で付ける。青色申告の65万円控除を狙うなら複式簿記の会計ソフトを使う(ソフトの選定・契約は社長の承認後)
5. 保存期間:帳簿・証憑は原則7年(条件により5年)【要確認】。削除しない

### 6-2. 売上の記録

- **売上は総額(ゲストの支払額、税抜)で計上し、ポータル手数料は経費(支払手数料)として別に記録**する。振込額(手取り)だけを売上にしない
- ポータルごとの売上明細(月次)をダウンロードし、振込額と突合する(月末締め翌月末払いなど、入金のずれに注意)
- キャンセル料も売上として記録し、それにかかる手数料も記録する
- 直接予約(将来)をする場合は、請求書の雛形を ai-admin が用意する。インボイス登録をするまでは登録番号を記載しない

### 6-3. 勘定科目の目安

| 支出 | 勘定科目の目安 |
|---|---|
| 家賃・共益費 | 地代家賃 |
| 電気・水道・ガス | 水道光熱費 |
| 光回線・スマートロック等の通信 | 通信費 |
| 予約管理ツール・会計ソフト等のサブスク | 支払手数料 または 通信費(毎年同じ科目にそろえる) |
| ポータル手数料・振込手数料 | 支払手数料 |
| 清掃外注 | 外注費 |
| 消耗品・10万円未満の備品 | 消耗品費 |
| 保険料 | 損害保険料 |
| 修理 | 修繕費 |
| 写真撮影・広告 | 広告宣伝費 |
| 開業前に払った準備費用(物件取得費を除く調査・打ち合わせ等) | 開業費(任意償却)【要確認】 |

### 6-4. 月次の締め(毎月5日まで)

1. 前月分の証憑がすべて保存されているか確認(operations.md A10 のリマインド)
2. ポータルの売上明細を保存し、売上台帳と振込額を突合
3. 第2章・第3章の表を更新し、運転資金の残高と撤退基準を確認
4. 予算(第1章)との差額が10%を超えた項目は理由を備考に書き、社長に報告
5. 結果の要約を ai-secretary が月次議事録に残す

### 6-5. 支払いの承認

- 支払い・契約・サブスクの申込は**社長が行う**。AI社員は見積の比較と記録まで
- 予備費の使用、予算を超える支出、年額1万円を超える新しいサブスクは、事前に社長の承認を取り、承認日を備考に書く

# レンタルスペース 収支シミュレーション レポート(初版)

- 作成:ai-analyst / 2026-09-26。計算:simulate.py → pl-monthly.csv / sensitivity.csv / target-check.csv / levers.csv
- 前提:concept.md(稼働率 20→30→45%、時間帯別単価、手数料30%、清掃2,000円/回・1予約4.7h、固定費16万円、初期投資250万円)。時間帯の埋まり方と1ヶ月目10%は仮定。実績はゼロで、市場データの一部は一次情報で未確認。物件確定後に引き直す。

## 結論(3行)

1. 目標どおり進めば、5ヶ月目が底(累積−26万円)、6ヶ月目に単月黒字(+1.7万円)、12ヶ月目に月+10.5万円。運転資金は最低でも124万円残り、資金ライン48万円には届かない。
2. ただし初期投資250万円の回収は開業から35ヶ月目で、2年では終わらない。3ヶ月目の損益も約−4万円ではなく約−6万円。
3. 最も効くレバーは、開業前は「家賃」、開業後は「土日祝の単価」。1予約の時間を短くしないこと。

## 損益分岐(式:16万円 ÷(単価×0.7 − 2,000/4.7)÷ 450h)

| 条件 | 分岐稼働率 |
|---|---|
| 単価2,500円・家賃12万円 | 26.8%(121h) |
| 単価2,481円(本シミュの時間帯ミックス) | 27.2% |
| 単価2,400円 | 28.3% |
| 単価1,500円(会議室のみ) | 56.9% |

家賃1万円ごとに約+1.7pt(8万円なら20.8%、15万円なら31.8%)。

## 投資回収(1〜6ヶ月は concept どおり、7〜12ヶ月で下の稼働率へ直線で伸び、以降は横ばい)

| 稼働率 | 定常の月利益 | 開業からの回収 |
|---|---|---|
| 30%(撤退ライン) | +1.7万円 | 120ヶ月超 |
| 35% | +4.6万円 | 67ヶ月目 |
| 40%(合格) | +7.6万円 | 45ヶ月目 |
| 45%(目標) | +10.5万円 | 35ヶ月目 |
| 50% | +13.5万円 | 29ヶ月目 |

sensitivity.csv の回収月数は「初月からその状態」の単純計算で、立ち上げ期の赤字を含まない。

## レバー(12ヶ月目・45%・月+10.5万円が基準)

| レバー | 月利益の変化 |
|---|---|
| 単価+10% | +3.5万円 |
| 稼働率+5pt | +2.9万円 |
| 手数料30→25% | +2.5万円 |
| 清掃2,000→1,500円 | +2.2万円 |
| 土日祝+300円/h | +2.1万円 |
| 家賃−1万円 | +1.0万円/月(10万円なら取得費も減り、回収は28ヶ月目) |
| 1予約4.7h→3.0h | −4.9万円 |
| 手数料の消費税を控除できない(実質33%) | −1.5万円 |

家賃は開業後に変えられず、損益分岐そのものを動かす唯一のレバー。開業後は、土日祝の単価とパック中心の販売(1予約の時間を長く保つ)が最も効く。

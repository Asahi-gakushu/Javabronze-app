## 1. KPIツリー

```
月の営業利益
├─ 手取り売上 = 売上 ×(1 − 手数料率)
│   ├─ 売上 = 予約時間 × 平均単価
│   │   ├─ 予約時間 = 450h × 稼働率
│   │   │   ├─ 平日昼の稼働率(189h枠)… 法人・定期利用件数、撮影パック件数
│   │   │   ├─ 平日夜の稼働率(126h枠)… 上映会パック件数
│   │   │   └─ 土日祝の稼働率(135h枠)… 3h/5hパック件数
│   │   │       └─ 共通の先行指標:ポータル閲覧数 → 問い合わせ・予約転換率、レビュー件数・平均点、リピート率
│   │   └─ 平均単価 = 時間帯ミックス × 各帯の単価(割引・直前割・商用加算)
│   └─ 手数料率 = ポータル別の売上構成(SM 30% / IB 35% / カシカシ 25% / 直接 0%)
├─ 清掃費 = 予約件数 × 1回単価
│   └─ 予約件数 = 予約時間 ÷ 1予約あたりの平均時間(4.7h)  ← 短時間予約が増えると悪化
└─ 固定費(家賃が75%)
```

## 4. concept.md の数字との食い違い・注意点

1. **3ヶ月目の損益は約−4万円ではなく約−6万円**。concept 自身の式で計算すると清掃費(19件 × 2,000円 = 約3.8万円)の分だけ赤字が大きくなる。−4万円は清掃費を約1.8万円しか見ていない計算になる。
2. **「12ヶ月45% = 2年回収ペース」は、開業から2年では回収できないという意味**。月10.8万円の利益で250万円を回収するのに約23ヶ月かかるのは、45%に達した12ヶ月目から数えた場合の話。立ち上げ期の赤字(累積で最大約26万円、5ヶ月目)を含めると、開業からの回収は**35ヶ月目**(24ヶ月時点の累積は+143万円で、残り107万円)。2年回収を開業起点にするなら、立ち上げを前倒しするか、45%より高い稼働率が要る(12ヶ月目以降50%横ばいでも29ヶ月目)。
3. **撤退ライン「12ヶ月で30%未満」は、ほぼ損益トントンの水準**。30%で横ばいだと月利益は約1.7〜1.9万円で、初期投資の回収に10年以上かかる。35%でも回収は67ヶ月目。「撤退しないが回収もできない」状態が長く続きうるので、12ヶ月時点で30〜35%の場合の扱い(条件付き継続の期限など)を決めておくべき。
4. **「会議室のみなら損益分岐は約50%」は楽観的**。単価1,500円・1予約4.7hでも損益分岐は約57%、1,250円なら約79%。会議利用は1予約が短い(1〜2h)ので、実際は清掃費でさらに悪化する。不採用の結論は変わらない。
5. **オープニング割引の期間**:2-3章は「1ヶ月だけ」、3-2章は3ヶ月目の単価2,200円を「割引の影響あり」としている。1ヶ月だけなら3ヶ月目は定価のはずで、どちらかにそろえる必要がある(本シミュレーションは1ヶ月だけ)。
6. **平均単価2,400〜2,500円は、土日祝がよく埋まることが前提**。本シミュの配分(売上時間の約50%が土日祝)で約2,481円。平日昼の比率が上がると平均単価は下がる(平日昼だけ1,500円)。
7. **手数料の消費税**:スペースマーケットは「30%+消費税」。免税事業者のままだと消費税分を差し引けず、実質33%になり、12ヶ月目の月利益が約1.5万円減る(`levers.csv`)。インスタベース(35%)の比率が高い場合も同程度悪化する。
8. 家賃1万円アップで損益分岐 +1.7pt(concept 1-5)は検算で一致(単価2,500円のとき+1.68pt)。

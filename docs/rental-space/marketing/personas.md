## ペルソナA:推し活・生誕祭の幹事「みさき」(主軸・売上の柱)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 27歳・女性・都内在住の会社員(事務職)。年収380万円。推し(男性アイドルグループのメンバー)歴6年 |
| 利用シーン | 推しの誕生日前後の土日に、同担の友人3〜5人と「生誕祭」。祭壇(アクスタ・ぬいぐるみ・うちわ)を作り、ケーキで祝い、ライブBlu-rayを大画面で上映。最後に全員で写真撮影 |
| 予約の決め手 | ①貸切で他人の目がない ②100インチ級の画面とHDMI/ミラーリング ③壁に飾れる(マステ・ピン可否が明記) ④写真映えする白壁・照明 ⑤最寄り駅から近い ⑥1人あたり3,000円以内 |
| 予算感 | 5時間で1.2万〜1.6万円(1人2,000〜3,500円)を割り勘。装飾品は自前で数千円 |
| 探し方 | X(旧Twitter)とInstagramで「#生誕祭 レンタルスペース」「#推し活ルーム」を検索 → 気になった部屋をインスタベース/スペースマーケットで空き確認。ポータルの特集一覧(生誕祭スタジオ、シアタールーム)も見る。他の人の祭壇写真が載ったレビューを重視 |
| 予約時期 | 推しの誕生日の1〜2ヶ月前。人気の日(誕生日当日・直前の土日)は先に埋まることを知っている |
| 不安・不満 | 「飾り付けが禁止だった」「プロジェクターの接続が分からず30分ロスした」「写真で見るより狭い・暗い」「ほかの予約とかぶって装飾が撤去時間に間に合わない」 |
| 刺さる言葉 | 「生誕祭の祭壇が作れる壁」「推しを100インチで」「装飾キット無料」「撤収30分込みのプラン」「6人までの貸切」 |
| リピート性 | 高い。同じグループの別メンバーの誕生日、ライブの配信鑑賞会、年末の上映会で年2〜4回(【推測】)。同担コミュニティで口コミが広がる |
| このルームのルールとの相性 | 良い。少人数で、騒ぐより「見て・撮って・語る」。22時退室・音量上限を不満に感じにくい |
| 注意 | 配信の上映は、配信サービスの規約上「私的な視聴」の範囲かどうかが論点になりうる【未確認】。掲載文では「上映内容の権利はゲストの責任」と書き、ai-writer が利用規約に入れる |

## ペルソナB:撮影利用のクリエイター「けんた」(副軸・平日昼の柱)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 32歳・男性・フリーランスのフォトグラファー兼動画編集者。個人のEC事業者やハンドメイド作家、インフルエンサーから撮影を請け負う |
| 利用シーン | 平日昼に2〜4時間。①アクセサリー・雑貨の物撮り ②SNS用のプロフィール・コスメ紹介撮影 ③YouTube/ショート動画の収録(トーク系) |
| 予約の決め手 | ①白壁(ホリゾント風)の面の広さ ②自然光か定常光の照明 ③電源の数とブレーカー容量 ④搬入のしやすさ(エレベーター・駅からの距離) ⑤商用撮影の料金が明確 ⑥静かさ(収録) |
| 予算感 | 半日4時間で5,000〜8,000円。スタジオ代は案件の見積もりに入れてクライアントに請求する |
| 探し方 | ポータルで「撮影」「白壁」「商用撮影可」に絞って検索。写真の中に床・壁・照明がどこまで写っているか、図面と寸法があるかを見る。気に入れば同じ部屋を使い続ける |
| 予約時期 | 数日〜2週間前。直前の空き枠もよく探す |
| 不安・不満 | 「写真と実物の色味が違う(壁が黄ばんでいる)」「商用撮影の追加料金が後から請求された」「隣の音が入る」「窓の光が強すぎて調整できない」 |
| 刺さる言葉 | 「白壁幅◯m」「定常光LED2灯無料」「商用撮影OK・料金明記」「平日半日パック6,800円」「電源◯口」 |
| リピート性 | 高い。月1〜4回の定期利用になりうる(【推測】)。コンセプトの「平日の定期利用 月4回以上で10%引き」の主なターゲット |
| このルームのルールとの相性 | 良い。平日昼で騒音リスクが低い。壁・床の傷と機材搬入のルールは必要 |

## ペルソナC:平日昼のビジネス利用「さとう課長」(副軸・稼働の下支え)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 45歳・男性・社員40人の中小企業(IT・人材・不動産など)の人事総務課長。オフィスは候補駅の近く、会議室は2つで取り合い |
| 利用シーン | ①中途採用の対面面接(1〜2時間) ②外部の人とのオンライン商談・オンライン面接を静かな個室で ③4〜6人の打ち合わせ・研修の動画視聴 ④社内の小さな懇親会(平日夜、少人数) |
| 予約の決め手 | ①駅・オフィスから近い ②Wi-Fiの速度(数値の記載) ③大画面モニター/プロジェクターにPCをつなげる ④領収書・インボイス対応 ⑤即時予約できる ⑥「パーティー感」が強すぎない写真 |
| 予算感 | 1時間1,000〜2,000円。会議室相場(4〜5人で1,000〜3,000円/時。レポート第3章)の範囲。会社の経費 |
| 探し方 | 会議室系ポータル(スペイシーなど)、Googleマップの「貸し会議室 ◯◯駅」、インスタベースの会議室カテゴリ |
| 予約時期 | 前日〜1週間前。予定が変わりやすくキャンセル規定を気にする |
| 不安・不満 | 「写真がパーティー部屋で、面接相手に失礼にならないか」「Wi-Fiが遅い」「領収書の宛名が変えられない」「インボイス番号がない」 |
| 刺さる言葉 | 「面接・商談用の会議配置写真あり」「Wi-Fi実測◯Mbps」「100インチでPC画面を共有」「適格請求書発行可」 |
| リピート性 | 中〜高。採用シーズン(【推測】中途は通年、新卒は春〜初夏)に集中。法人の定期利用はai-salesの営業対象 |
| このルームのルールとの相性 | 良い。騒音リスクなし。単価は低いが平日昼の空き枠を埋める |
| 注意 | インボイス対応は社長の決定事項(concept.md 第5章#4)。未登録なら「適格請求書は発行できません」と明記し、不満レビューを防ぐ |

## 3人をどう使い分けるか

| ペルソナ | 主な時間帯 | 主な窓口 | 掲載文・写真の見せ方 | 目標の売上構成(【推測】concept.md の65%想定に合わせた) |
|---|---|---|---|---|
| A 推し活・生誕祭 | 土日祝・平日夜 | インスタベース、スペースマーケット、X/Instagram | シアター配置+祭壇の飾り付け例 | 約60〜65% |
| B 撮影クリエイター | 平日昼 | スペースマーケット、インスタベース(撮影カテゴリ)、リピート | 白壁面・照明・寸法図 | 約20% |
| C ビジネス | 平日昼・平日夜 | スペイシー等の会議系ポータル、Googleマップ、ai-sales の直接営業 | 会議配置・モニター接続・Wi-Fi速度 | 約15〜20% |

- 1室で3つの顔を見せるため、**ポータルには用途別に写真の1枚目を変えた掲載(またはプラン)を作る**(詳細は plan.md 施策S2)。同じ部屋を複数ページで掲載してよいかはポータルの規約で【未確認】。
- 開業3ヶ月後に、実際の予約の用途とレビューの内容でペルソナを見直す(ai-analyst の用途別集計を使う)。

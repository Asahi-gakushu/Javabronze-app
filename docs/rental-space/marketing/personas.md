## ペルソナA:推し活・生誕祭の幹事「みさき」(主軸A・売上の柱)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 27歳・女性・会社員(事務職)。推し(アイドルグループのメンバー)歴6年。同担の友人3〜5人 |
| 利用シーン | 推しの誕生日前後の土日に「生誕祭」。祭壇を作り、ケーキで祝い、ライブ映像を大画面で上映。**乾杯は持ち込みのお酒かノンアル**。最後に全員で写真 |
| 決め手 | ①貸切 ②大画面とHDMI・ミラーリング ③壁に飾れる(可否の明記) ④写真映え ⑤駅から近い ⑥1人3,000円以内 |
| 予算 | 休日5時間パック15,800円を5人で割って1人約3,200円 |
| 探し方 | X・Instagram の「#生誕祭 レンタルスペース」→ ポータルの特集一覧(生誕祭・シアター・推し活)で空き確認。祭壇写真つきのレビューを重視 |
| 予約時期 | 誕生日の1〜2ヶ月前 |
| 不安 | 飾り付け禁止、接続トラブル、写真より狭い・暗い、撤収が間に合わない |
| 刺さる言葉 | 「推しと晩酌」「祭壇が作れる壁」「大画面(80〜100インチ)」「6人まで貸切」「23時まで」 |
| ルールとの相性 | 良い。「見て・撮って・語る」が中心で、22時からの静音タイムを不満に感じにくい |
| リピート | 年2〜4回(別メンバーの生誕・配信鑑賞・年末上映会) |

## ペルソナD【新規】:家に呼べない晩酌グループ「ゆうと」(主軸B・晩酌)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 29歳・男性・会社員(営業)。ワンルーム住まい。職場の同期や学生時代の友人2〜4人で「家飲みしたいが、誰の家も狭い・壁が薄い」 |
| 利用シーン | ①**平日19〜22時の仕事帰りの晩酌**(コンビニ・スーパーで買って持ち込み、デリバリーを頼む) ②休日の午後〜夜に、サッカー・野球・格闘技の配信を大画面で観ながら飲む ③「推しを見ながら晩酌」(Aと重なる一番の売れ筋) |
| 決め手 | ①居酒屋より安い(1人2,000円前後+持ち込み代) ②**周りを気にせず話せる個室** ③冷蔵庫・電子レンジ・グラスがある ④ゴミを捨てて帰れる ⑤駅から近い、帰り道にある |
| 予算 | 晩酌3時間パック7,800円を4人で1人1,950円。飲み物・つまみで1人1,000〜1,500円 |
| 比較対象 | 居酒屋の個室・飲み放題、カラオケ、友人宅(`competitors.md` ⑦⑧⑥) |
| 探し方 | ポータルの「宅飲み」「飲み会」一覧、Googleマップの「レンタルスペース 駅名」。**当日〜3日前の直前予約が多い** |
| 不安 | 「うるさいと怒られないか」「ゴミの捨て方が面倒」「グラスや皿が汚い」「追加料金が不明」 |
| 刺さる言葉 | 「家飲みの代わりに」「冷蔵庫・レンジ・グラスあり」「ゴミはそのまま捨てて帰れる」「4人で1人1,950円」「23時まで」 |
| ルールとの相性 | **注意が必要**。22:30で飲酒終了・コール禁止・泥酔者の入室不可を**予約前に**見せ、騒ぎたい層が予約前に離れるようにする。20歳以上の確認を予約時に行う |
| リピート | 月1回の定例になりうる。給料日の後と金曜に集中 |

## ペルソナE【新規】:平日休みの推し活・昼飲み「あや」(平日昼の柱)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 31歳・女性・看護師(シフト制)。同じ推しの仲間にも販売員・美容師・介護職など平日休みの人が多い |
| 利用シーン | 平日の11〜16時に2〜4人で、配信ライブのアーカイブや円盤の鑑賞会+**昼飲み**(11時から飲酒可)。夜勤明けの人は昼過ぎから |
| 決め手 | ①**平日昼が安い**(4時間パック5,800円=3人で1人約1,930円) ②土日の予約合戦に参加しなくてよい ③昼でも暗くできる(遮光カーテン)④カフェやカラオケより長く、ゆっくり話せる |
| 探し方 | X の推し仲間のつながり、ポータルで「平日 推し活」「昼飲み」。シフトが出た直後(月の中旬〜下旬)にまとめて予約 |
| 予約時期 | 1〜3週間前(シフト確定後) |
| 不安 | 「前の利用者のお酒の匂いが残っている」「平日昼なのに料金が高い」 |
| 刺さる言葉 | 「平日休みの推し活に」「平日昼は1時間1,500円」「昼飲みOK(11時から)」「遮光で昼でも上映」 |
| ルールとの相性 | 良い。昼の利用で騒音リスクが低い |
| 意味 | 平日昼は分母510時間の3分の1(168時間)。撮影・会議より先に、この層で埋める(concept 1-3) |

## ペルソナF【新規】:遠征の朝の身支度「ちひろ」(早朝枠 6〜9時)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 24歳・女性・地方在住(例:東北・関西)の会社員。年に数回、首都圏のアリーナ・ドーム公演に**夜行バスか始発の新幹線・早朝便**で来る。同じ公演に行く友人1〜2人と合流 |
| 利用シーン | 6〜9時に2〜3時間。着替え、ヘアメイク、うちわ・グッズの準備、キャリーケースの整理、仮眠ではなく「座って休む」。その後グッズ列や会場へ |
| 決め手 | ①**朝6時から入れる** ②全身鏡・明るい照明・コンセントが多い ③キャリーを広げられる ④夜行バスの降車地・会場へ乗り換えなしで行ける ⑤1人1,000〜1,500円程度 |
| 予算 | 朝の3時間パック3,000円を2〜3人で割る(1人1,000〜1,500円)。比較対象はバスターミナルのパウダールーム、カラオケ、漫画喫茶、WILLER連携の早朝スペース(1時間700〜1,500円) |
| 探し方 | 「夜行バス 着替え 駅名」「遠征 朝 身支度」で検索、X の遠征アカウントのまとめ、ポータルの「着替え・メイク」特集 |
| 予約時期 | 公演の2〜4週間前(チケット当選後)。**当方の早朝枠は前々日まで・承認制**なので、合っている |
| 不安 | 「本当に6時に入れるか」「前の利用者のお酒の匂い」「駅から迷う(土地勘がない)」「荷物を置いたまま出られるか(不可と明記する)」 |
| 刺さる言葉 | 「朝6時から|遠征の身支度に」「全身鏡・ドライヤー用コンセント」「◯◯(会場)まで乗り換えなし◯分」「朝は飲酒なしの清潔な部屋」 |
| ルールとの相性 | 良い。朝は飲酒不可、静か。**仮眠・横になる利用は受けない**(旅館業法の観点、concept 1-1)ので「休憩」は「座って休む」と書く |
| サブ層F2 | **早朝の観戦・朝活**:海外スポーツの生中継を朝に観る2〜4人(時差の関係で日本時間の朝になる試合がある【推測】)、出勤前のオンライン面接・勉強。どちらも少数と見る |

## ペルソナG:副次の撮影・会議「けんた/さとう」(副次・売上の約15%)

| 項目 | 内容(すべて【推測】) |
|---|---|
| 基本 | 物撮り・SNS撮影をする個人事業者(けんた)、近隣の中小企業の面接・少人数会議(さとう) |
| 扱い | **掲載はするが、写真の1枚目・ブランド名・SNSには出さない**。白壁1面とHDMI接続で対応できる範囲だけ。撮影照明・モニター・ホワイトボードは置かない(concept 1-4・1-8) |
| 刺さる言葉 | 「平日昼1時間1,500円」「白壁あり・商用撮影は+1,000円/時」「プロジェクターにHDMIでPC画面」 |
| 注意 | 前夜の晩酌の匂いがあるとレビューが下がる。清掃チェックの「換気・消臭」を必須に。インボイスは開業時は未登録なので「適格請求書は発行できません」と明記 |

## ペルソナの使い分け

| ペルソナ | 主な時間帯 | 主な窓口 | 写真・掲載文の見せ方 | 売上構成の目安【推測】(concept 1-1 に合わせる) |
|---|---|---|---|---|
| A 推し活・生誕祭 | 土日祝・平日夜 | ポータル特集(生誕祭・シアター・推し活)、X・Instagram | **1枚目**:大画面に映像+祭壇+ローテーブルにグラス | 約40% |
| D 晩酌グループ | 平日夜・土日の夕方以降 | ポータル「宅飲み・飲み会」、Googleマップ | 2〜3枚目:晩酌配置(冷蔵庫・グラス・ゴミ箱)、ハウスルールの要約 | 約30% |
| E 平日休みの推し活・昼飲み | 平日昼 | X の推し仲間、ポータル | 平日昼パックのプラン名と料金 | 約12%(A・Dの平日昼版を含む) |
| F 遠征の朝(+F2) | 早朝 6〜9時 | ポータル「着替え・メイク」特集、遠征系の検索・X | 全身鏡・コンセント・キャリーを置いた写真、会場への行き方 | 約3% |
| G 撮影・会議(副次) | 平日昼 | ポータルの撮影・会議カテゴリ(開業後3ヶ月以内) | 写真の後半に白壁と会議配置を1〜2枚 | 約15% |

- 「推し活50%・晩酌35%」は、A(40%)+E のうち推し活(約5%)+F(約3%)≒推し活系約48%、D(30%)+E のうち昼飲み(約7%)≒晩酌系約37%、として概ね合わせた【推測】。
- 開業3ヶ月後に、予約の用途申告(推し活/晩酌/早朝の身支度/撮影/会議/その他)と時間帯4区分で見直す(ai-analyst の集計と同じ区分)。

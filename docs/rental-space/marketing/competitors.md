# レンタルスペース事業 競合比較・差別化軸・候補駅の選び方(第2版:コンセプト第3版対応)

- 作成:ai-marketer / 初版:2026-09-26 / 第2版:2026-09-26
- 前提:`strategy/concept.md` 第3版(「推しと晩酌」、6〜23時、家賃は共益費込み7万円以下、駅徒歩8分以内、住戸のない建物、飲食店が入るビルの2階以上が加点)
- 凡例:**【事実】**=出典に書かれていること(WebFetch はプロキシで遮断されるため、すべて検索結果の要約経由。個別の部屋の料金・評価は未取得)/**【推測】**=当方の仮説
- 個別の部屋の比較表は、候補駅を絞ったあと第4章の手順で埋める(閲覧のみ。問い合わせ・予約による調査は社長の承認なしに行わない)

## 3. 比較すべき観点(候補駅ごとに調べる)

| 分類 | 観点 | 使い道 |
|---|---|---|
| 需要 | 駅で絞ったポータル掲載数(全体/推し活・シアター/**宅飲み・飲み会**/**着替え・メイク**/撮影/会議) | 競合密度と需要の代理指標 |
| 需要 | 駅前の飲食店街の規模、ライブ会場・夜行バス降車地・空港への所要時間(乗り換え回数) | D・F の母数【推測の代理指標】 |
| 競合 | ①②⑦の上位5室の時間単価(早朝/平日昼/平日夜/休日)、パック、最低利用時間、**飲酒可否・退室時刻・ゴミの扱い** | 料金とルールの妥当性 |
| 競合 | 上位5室のレビュー件数・平均評価・不満(騒音・ゴミ・清潔・接続) | 新規が勝てる余地 |
| 稼働 | 上位5室の4週先の予約の埋まり(公開範囲) | 需要の直接の手がかり |
| コスト | **事業用 10〜15㎡・徒歩8分以内・住戸なし・2階以上で共益費込み7万円以下**の募集件数 | 必須条件5・7・8を満たす物件があるか |
| リスク | 駅前が繁華街・住宅街のどちらか、建物の用途(住戸の有無) | 騒音・契約解除リスク |

## 4. 調べ方(候補駅ごとに実施)

1. **ポータル検索**:インスタベース・スペースマーケット・スペイシー・カシカシで「駅名」+(推し活/上映会/宅飲み/飲み会/着替え/撮影/会議)の件数を記録
   - 参考:[インスタベース 推し活・オタ活](https://www.instabase.jp/tokyo/list/fan-activities)、[インスタベース 宅飲み](https://www.instabase.jp/tokyo/list/drinking-at-home)、[カシカシ 着替え・メイク](https://kashispace.com/topics/changeclothes)、[カシカシ 推し会](https://kashispace.com/room/city/59)
2. **上位5室の詳細**:第3章の項目を記録。レビューは直近20件の不満の種類を数える
3. **区の平均単価**:カシカシの区別ページに平均時間単価などが出ている(例:[足立区](https://kashispace.com/room/city/121)、[大田区](https://kashispace.com/room/city/149))【事実:ページの存在のみ。数値は未取得】
4. **家賃**:不動産ポータル(アットホーム・貸事務所ドットコム・飲食店ドットコム)で**事業用・10〜15㎡・徒歩8分・共益費込み7万円以下**を5件以上記録。「住戸なし」「飲食可」「24時間ゴミ置き場」の記載も控える(ai-admin の内見チェックリストと共有)
5. **SNS**:「#駅名 レンタルスペース」「#駅名 宅飲み」「遠征 駅名 着替え」の直近3ヶ月の投稿数
6. **Googleマップ**:「レンタルスペース 駅名」の件数と上位の口コミ数

## 5. 駅選びの判定の目安(【推測】数値は仮置き。ai-analyst と調整)

| 判定 | 条件 |
|---|---|
| 有望 | 第6章の点数が70点以上、かつ**共益費込み7万円以下・10㎡以上・必須条件を満たしそうな事業用物件の募集が3件以上**、かつ同コンセプト(①②⑦で推し活×飲酒を打ち出す部屋)が半径500m内に3室以下 |

## 6. 候補駅・エリアの選定基準と候補例【新設】

### 6-1. 家賃7万円で借りられる広さの目安

| 項目 | 内容 |
|---|---|
| 【事実】 | 東京都の賃貸オフィスの平均坪単価は23,986円(2026年6月)、20〜30坪の小規模区画は21,111円/坪 [officee 東京都の賃料相場](https://officee.jp/price/tokyo)(検索要約経由) |
| 【事実】 | 北千住では共益費込み坪2.0〜2.3万円の貸事務所の募集がある [貸事務所ドットコム東京 北千住(坪単価20,000〜23,000円)](https://tokyo.kashi-jimusho.com/list/11402/F20000-23000/) |
| 【事実】 | 赤羽は賃貸オフィスビルが少なく、賃料相場は高めで安定しているという記載 [アットホーム 赤羽駅の貸事務所](https://www.athome.co.jp/rent_office/tokyo/akabane-st/list/) ほか(検索要約経由) |
| 【計算】 | 7万円 ÷ 坪2.0万円 = 3.5坪(約11.6㎡)。7万円 ÷ 坪2.3万円 = 約3坪(約10㎡)。**15㎡(約4.5坪)を7万円で借りるには坪1.55万円以下が必要** |
| 【推測】 | 23区の駅徒歩8分・事業用で7万円なら、**現実的な広さは10〜12㎡(定員4名)**。定員6名に必要な15㎡前後は、築古・空中階・駅から6〜8分・23区の外縁か埼玉側でないと難しい。小さい区画ほど坪単価が高くなりやすい点にも注意(上の平均は20〜30坪の値) |

- **ai-ceo への確認事項**:定員6名(15㎡前後)と家賃7万円は両立しにくい可能性がある。「10〜12㎡・定員4名で開業」を選ぶと、1予約の人数が減り、1人あたりの負担が上がる(晩酌3時間パックを4人で1人1,950円→3人で2,600円)。第3章の単価2,700円を保てるかを ai-analyst に確認してほしい。

# レンタルスペース事業 集客施策プラン(開業前〜12ヶ月・初版)

- 作成:ai-marketer / 作成日:2026-09-26
- 前提:`docs/rental-space/strategy/concept.md`(目標:稼働率 3ヶ月20%・6ヶ月30%・12ヶ月45%、レビュー3ヶ月20件・平均4.7以上)、`personas.md`、`competitors.md`
- 凡例:**【事実】**=出典に書かれていること(検索結果の要約経由。一次ページはプロキシで取得できず)/**【推測】**=当方の仮説・仮置きの数値
- 外部への投稿・掲載・公開・広告出稿・支払いは、**すべて社長の承認後**に行う(本書は計画のみ)

---

## 結論(5行)

1. 最優先は**ポータル掲載の作り込み**(1枚目の写真・タイトル・即時予約・返信速度)と**開業1〜3ヶ月のレビュー獲得**。ポータルの検索順位はレビューと対応品質で決まるため、ここが全施策の土台になる。
2. SNS は「推し活の写真が自然に投稿される部屋」を作ることに集中する。運営アカウントの発信は週2〜3回の軽い運用にとどめる。
3. MEO(Googleマップ)は無料で競合が少ないが、無人スペースが登録できるかどうかは【未確認】。開業前に確認し、登録できれば平日昼のビジネス需要を取る。
4. リピート施策はポータル内で完結させる(外部への誘導は規約違反になりうる)。季節イベントは「推しの誕生日カレンダー」と年末の上映会が中心。
5. KPI は ai-analyst と共通の**「表示数 → 閲覧 → 予約 → レビュー」**のファネルで毎週測る。目標値の多くは【推測】なので、開業1ヶ月目の実績で引き直す。

## 1. KPI の設計(ai-analyst と共通の定義)

### 1-1. ファネルの定義

| 段階 | 指標 | 定義 | 取得元 |
|---|---|---|---|
| ① 表示 | 表示数 | ポータルの検索結果・特集一覧に部屋が表示された回数(ポータル別) | 各ポータルのホスト管理画面。**どのポータルで取れるかは【未確認】**。スペースマーケットには実績を確認する画面がある【事実】[ホストアカデミー 実績の確認方法](https://academy.spacemarket.com/records/)(検索要約経由。項目は未確認) |
| ② 閲覧 | 閲覧数(PV) | 部屋の詳細ページが開かれた回数 | 同上 |
| ③ 予約 | 予約件数・予約時間 | 確定した予約の件数と合計時間(キャンセル後の数字) | ポータルの予約CSV → ai-programmer の集計スクリプト(concept.md P2) |
| ④ レビュー | レビュー件数・平均評価 | 利用後に投稿されたレビュー | ポータル画面(手入力でも可) |

| 転換率 | 計算式 | 何を見るか | 効く施策 |
|---|---|---|---|
| 閲覧率(CTR) | ② ÷ ① | サムネイル・タイトル・価格表示の強さ | S1, S2 |
| 予約率(CVR) | ③件数 ÷ ② | 写真2枚目以降・説明文・空き状況・レビュー | S1, S2, S3 |
| レビュー率 | ④件数 ÷ ③件数(利用済みのもの) | 体験の質と依頼の仕方 | S4 |
| リピート率 | 2回目以降の予約件数 ÷ 予約件数(月次) | 満足度・リピート施策 | A3 |

- 最終KPI(concept.md と同じ):**稼働率 = 予約時間 ÷ 月450時間**、平均単価(手数料差し引き前/後の両方)、時間帯別稼働率(平日昼・平日夜・休日)。
- 集計は**ポータル別 × 用途別(推し活/撮影/ビジネス/その他)× 時間帯別**。用途は予約時の申告欄から取る。
- 表示数・閲覧数が取れないポータルは ③④ だけ測り、「取れない」と明記する(推定値で埋めない)。

### 1-2. 目標値(【推測】開業1ヶ月目の実績で必ず引き直す)

逆算の前提:予約1件あたり平均4時間(休日の長時間と平日の短時間の混合を【推測】で仮置き。レポートの平均4.7時間より短め)。

| 時点 | 稼働率(concept.md) | 予約時間/月 | 予約件数/月 | 閲覧→予約 | 閲覧数/月 | 表示→閲覧 | 表示数/月 | レビュー(累計) |
|---|---|---|---|---|---|---|---|---|
| 1ヶ月目 | 10%(【推測】) | 45 | 約11 | 2.0% | 約550 | 2.5% | 約22,000 | 5件 |
| 3ヶ月目 | 20% | 90 | 約22 | 2.5% | 約900 | 3.0% | 約30,000 | **20件・平均4.7以上** |
| 6ヶ月目 | 30% | 135 | 約34 | 3.0% | 約1,100 | 3.5% | 約32,000 | 45件 |
| 12ヶ月目 | 45% | 約200 | 約50 | 3.5% | 約1,450 | 4.0% | 約36,000 | 100件 |

- 転換率(2〜4%)は業界の公表値が見つからなかったため**すべて仮置き**。
- 3ヶ月で20件は、3ヶ月の予約合計(約11+17+22=50件)の**レビュー率40%**が必要。依頼を仕組みにしないと届かない(施策S4)。
- 補助KPI:返信時間の中央値(1時間以内)、承認率100%、キャンセル率、清掃の指摘件数、苦情ゼロ(騒音・近隣)。

## 2. 施策一覧(優先順位つき)

優先度:**S**=開業前に必ずやる/**A**=開業後3ヶ月以内/**B**=4ヶ月目以降、余力で。
コストは「お金」と「社長の作業時間」を分ける。金額は【推測】。

### S1. ポータル掲載の作り込み(写真)

| 項目 | 内容 |
|---|---|
| 内容 | プロのカメラマンに撮影を依頼。**1枚目=大画面に映像が映り、壁に祭壇の飾り付けがあるシアター配置**(ペルソナA)。2枚目以降:白壁面と照明(B)、会議配置とモニター接続(C)、入口・水回り・備品一覧・装飾キット・図面(寸法入り)。20〜30枚。昼と夜の2パターン |
| 根拠 | インスタベースは水回りや備品の写真の掲載が予約につながると案内している【事実】[インスタベース 予約件数を増加させるには](https://support.instabase.jp/hc/ja/articles/360001591991)(検索要約経由)。スペースマーケットは時間貸しで寝具の写真・文言を載せることを禁止【事実】[スペースマーケット ホストの禁止行為](https://spacemarket.zendesk.com/hc/ja/articles/360032198251)(検索要約経由) → ソファで横になる構図などは避ける |
| 期待効果 | 閲覧率・予約率の底上げ。競合との差(軸1)が一目で伝わる【推測】 |
| コスト | 3〜8万円(concept.md の掲載準備8万円の範囲)。撮影指示書は ai-designer、装飾の小物は装飾キットと共用 |
| KPI | 閲覧率(CTR)、予約率(CVR)。写真差し替えの前後2週間で比較 |

### S2. ポータル掲載の作り込み(タイトル・説明文・プラン)

| 項目 | 内容 |
|---|---|
| 内容 | タイトルは「駅名+徒歩分+用途キーワード+差別化」。例(【推測】):「◯◯駅3分|100インチで推し活・生誕祭|飾れる壁と撮影照明|6名貸切」。説明文の冒頭3行で「定員6名・22時退室・音量上限」を宣言。用途別プラン(休日5時間パック、平日夜上映会パック、平日撮影半日パック、面接・商談プラン)。ポータルの特集カテゴリ(生誕祭・シアター・上映会・推し活・撮影・会議)に該当する用途タグを全部付ける |
| 根拠 | ポータル各社に「生誕祭スタジオ」「貸切シアタールーム」「上映会・鑑賞会」「推し活・オタ活」の特集一覧がある【事実】(competitors.md 第1章の出典) |
| 期待効果 | 表示数(特集・検索への露出)と閲覧率の向上。騒ぎたいグループが予約前に離れる(騒音リスクの低減) |
| コスト | 0円。ai-writer が用途別3種の掲載文を作成(concept.md P2)。社長の確認1〜2時間 |
| KPI | 表示数、閲覧率、用途別の予約件数の構成比 |

### S3. 検索順位を上げる運用設定(即時予約・返信速度)

| 項目 | 内容 |
|---|---|
| 内容 | ①即時予約(今すぐ予約)をオンにする ②問い合わせへの返信を1時間以内(スマホ通知+定型文) ③予約の承認率100%を保つ ④複数ポータルのカレンダーを一元管理してダブルブッキングとホスト都合のキャンセルをゼロに(ツールは ai-admin) |
| 根拠 | インスタベースは承認率の高さ・高評価レビューの多さ・「今すぐ予約」の設定が上位表示に影響すると説明【事実】[インスタベース 検索順位で上位に表示させるには](https://support.instabase.jp/hc/ja/articles/360001575072)。スペースマーケットはスペース情報・予約とメッセージ(承認率・返答率・返信時間)・ゲスト満足度(レビュー)の3軸で評価【事実】[ホストアカデミー 検索順位の評価基準](https://academy.spacemarket.com/up-to-date_hyoka/)(いずれも検索要約経由) |
| 期待効果 | 表示数(検索順位)の向上。新規の部屋でも上位に出る条件をそろえる |
| コスト | お金0円+一元管理ツールの月額(レポートの固定費5,000円に含む)。社長の返信対応 1日10〜20分【推測】 |
| KPI | 表示数、返信時間の中央値、承認率、ホスト都合キャンセル件数(0件) |

### S4. 最初のレビュー獲得(開業1〜3ヶ月)

| 項目 | 内容 |
|---|---|
| 内容 | ①オープニング価格20〜30%引きを1ヶ月(concept.md 2-3) ②退室時の案内(室内のPOPと入室案内メール)で「レビューが次のゲストの参考になります」とお願いする ③利用翌日にポータルのメッセージでお礼+レビュー依頼 ④全レビューに48時間以内に返信 ⑤低評価の原因は1週間以内に改善し、返信で改善内容を書く ⑥清潔さを最優先(社長が最初の1ヶ月は自分で清掃し、チェックリストで品質を固定) |
| 根拠 | インスタベースでは最高評価レビューの約4割が「清潔感」と「親切な対応」に関する内容【事実】[インスタベース 高評価のレビューを多く獲得するには](https://support.instabase.jp/hc/ja/articles/360001575112)(検索要約経由) |
| 注意 | **レビューと引き換えの特典(割引・プレゼント)はポータルの規約違反になりうる【未確認】**。規約を確認するまでは「お願い」だけにする。知人に頼んだ架空の予約・レビューは絶対にしない |
| 期待効果 | レビュー率40%で3ヶ月20件(目標)。検索順位と予約率の両方が上がる |
| コスト | 割引の機会損失:1ヶ月目の売上約10万円の20〜30%=約2〜3万円【推測】。依頼文・POPは ai-writer、POPの印刷は数百円 |
| KPI | レビュー率、レビュー件数(累計)、平均評価、「清潔」への言及数 |

### S5. 掲載ポータルの選定と開始順

| 項目 | 内容 |
|---|---|
| 内容 | 開業時はインスタベース+スペースマーケットの2社(concept.md 第5章#9の推奨)。平日昼向けに3ヶ月目までに会議系1社(スペイシー等)を追加。カシカシは手数料25%と安いが知名度は低め【事実:レポート第2章】なので、4ヶ月目以降に追加を検討 |
| 期待効果 | 表示数の母数を増やす。ポータル別の予約率を比べて、手数料込みの手取りが良い所に力を入れる |
| コスト | 掲載料0円(成果報酬25〜35%)。登録作業 各2〜3時間 |
| KPI | ポータル別の表示数・予約件数・手取り売上。**手数料差し引き後**で比較 |

### A1. SNS(Instagram と X)

| 項目 | 内容 |
|---|---|
| 内容 | ①運営アカウントを開設し、「祭壇の飾り付け例」「100インチでの上映の様子(映像は権利に配慮しダミー)」「撮影の作例」を週2〜3回 ②部屋にハッシュタグ(#部屋名、#駅名生誕祭 など)のPOPを置き、ゲストの投稿を促す ③ゲストの投稿は許可を得てから紹介(リポスト) ④推しの誕生日が近いグループ名での検索を見て、投稿のテーマを決める |

| コスト | 0円。投稿文は ai-writer、画像の指示は ai-designer。社長の作業 週1時間【推測】 |
| KPI | フォロワー数、ハッシュタグ付きのゲスト投稿数/月、SNSからポータルへのリンククリック数(短縮URLで計測)、予約時の「どこで知ったか」回答 |

### A2. MEO(Googleビジネスプロフィール)

| 項目 | 内容 |
|---|---|
| 内容 | ①開業前に、無人のレンタルスペースが登録対象になるかを確認 ②対象なら、写真10枚以上、営業時間、カテゴリ、予約リンク(ポータルのページ)を登録 ③口コミへの返信、月2回の投稿 |
| 根拠 | Googleのガイドラインでは、掲載できるのは営業時間内に顧客と直接やり取りするビジネスだが、ATMや無人のビデオレンタル店などのセルフサービス型は、顧客が使える連絡先を載せれば許可される【事実】[Google ビジネス プロフィール 適格性のガイドライン](https://support.google.com/business/answer/13763036?hl=ja)(検索要約経由)。レンタルスペースで MEO をしている所は少なく上位を取りやすいという業者の主張がある【事実(二次情報・業者の宣伝)】[ユウカツブログ](https://yukatsu.jp/blog/rentalspace_meo/)、[スペチョク](https://spe-choku.com/blog/google-business-profile/)。スペースマーケットも Googleビジネスの活用を紹介している【事実】[ホストアカデミー Googleビジネス活用](https://academy.spacemarket.com/knowhow_g-business/) |
| 注意 | **無人のレンタルスペースが「セルフサービス型」として認められるかは【未確認】**。住所の確認方法(はがき・動画など)も事前に確認する。不適格なのに登録すると停止のリスクがある |
| 期待効果 | 「貸し会議室 駅名」「レンタルスペース 駅名」での地図表示。平日昼のビジネス利用(ペルソナC)の流入【推測】 |
| コスト | 0円。社長の作業 初回2時間+月1時間 |
| KPI | GBPの表示回数・ウェブサイト(予約リンク)クリック数・ルート検索数(GBPの管理画面で取れる)、Google口コミ件数 |

### A3. リピート施策(ポータル内で完結)

| 項目 | 内容 |
|---|---|

| コスト | 0円(割引を使う場合は割引分)。文面は ai-writer |
| KPI | リピート率、お気に入り登録数(取れれば)、定期利用の件数/月 |

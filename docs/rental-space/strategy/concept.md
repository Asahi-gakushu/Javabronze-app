## 結論(5行)

1. **コンセプト**:「推しと飲める、6人までの小さな部屋」。主軸は**推し活**(上映会・生誕祭・配信の視聴)と**晩酌**(2〜6人で家飲みの代わりに使う)。撮影と会議は平日昼の空き時間を埋める**副次的な用途**で、そのための投資はしない。
2. **1年回収は「条件がそろえば届く」が、余裕はない**。家賃7万円以下・初期投資110万円以下・平均単価2,700円・清掃1回1,500円・稼働率(月510時間が分母)3ヶ月20%→6ヶ月30%→12ヶ月40%の**5つがすべてそろって、ちょうど12ヶ月目に回収**できる。単価が2,500円なら13ヶ月目、立ち上げが遅れれば20ヶ月目前後になる。
3. **そこで目標は「12ヶ月で回収」とし、資金計画と撤退基準は「18ヶ月で回収」を前提に組む**。必要な資金は、初期投資110万円と運転資金70万円を合わせた**180万円**(第2版では400万円)。
4. **物件の必須条件は8つ**(1-6)。新たに加えたのは「**家賃は共益費込みで7万円以下**」「**24時間出せるゴミ置き場を、時間貸しの利用者が使ってよいという書面**」「**飲酒と6〜23時の営業を認める書面**」「**住戸がない建物**」。飲食店が入居できる雑居ビルの空中階が第一候補。
5. **晩酌を認めるので、騒音とトラブルへの対策を最初から売り物にする**。「22時から静音タイム」「22時30分に飲酒終了」「早朝は飲酒不可」「泥酔者は入室不可」の4つを掲載文に明記し、騒音センサーによる3段階の対応を規約に入れる(1-5)。

### 1-2. スペース名(U-01 の統一方針)

- 社長の決定により、第2版で仮に決めた「ROOM6」や「シアタールーム six」のような**用途が伝わらない名前は採用しない**。名前を見ただけで「推し活」と「晩酌」に使えると分かるものにする。
- **推奨する候補**(商標と同名のスペースを確認したうえで社長が最終決定する):
  1. **「推しと晩酌」**(第1候補):検索されやすい言葉が2つとも入っていて、説明がいらない
  2. 「おしばん」(推し+晩酌):短くて呼びやすい。ただし意味が伝わりにくいので、副題が必要になる
- ポータルでの掲載名は「推しと晩酌|◯◯駅徒歩◯分|大画面で上映会・家飲み|6名まで」のような形にする(駅名で検索されても見つかるように)。

### 1-4. 撮影・会議を副次扱いにしてよいか(判断)

**結論:副次扱いにする。ただし掲載はやめない。**

- 理由1:推し活と晩酌で、部屋の見せ方(ソファ・ローテーブル・装飾壁・大画面)がそろう。撮影・会議のための設備(撮影照明・背景紙・モニター・ホワイトボード)に投資すると、1年回収の予算を超える。
- 理由2:第2版の試算では、会議室として使った場合の損益分岐は稼働率約57%で、事業の柱にはならない。
- 理由3:それでも平日昼の168時間を少しでも埋める価値はある。白い壁面(壁紙の1面)と、中古の撮影照明1セット(予算に余裕があれば)で対応し、会議系のポータルには開業後3ヶ月以内に掲載する。
- 注意:前の利用者の晩酌の匂いや汚れが残っていると、昼の撮影・会議の利用者の評価が下がる。清掃チェックに「換気・消臭」を入れる(1-5 の7)。

### 1-5. 晩酌を認めることへの対策(ハウスルール)

晩酌は、第2版で見送った「大人数で飲むパーティー」とは違う。**少人数で静かに飲む**ことを、ルールと物件の両方で守る。

| # | ルール | ねらい |
|---|---|---|
| 1 | 定員6名(乳幼児を含む)。予約者は20歳以上。20歳未満の飲酒は禁止し、見つけた場合はその場で退室してもらう | 未成年の飲酒と大人数化を防ぐ |
| 2 | **飲酒は11:00〜22:30のみ**。早朝枠(6〜9時)は飲酒不可 | 朝から飲むこと・長時間の飲酒を防ぐ |
| 3 | **22:00からは静音タイム**。サウンドバーの音量上限を自動で下げる(スマートリモコンで設定)。乾杯のコール・合唱・手拍子・カラオケは終日不可 | 夜間の騒音を防ぐ |
| 4 | 22:30から片付けとゴミ出し、**22:45までにゴミ置き場へ出し終え、23:00までに退室** | 23時ちょうどに共用部が混雑するのを防ぐ |
| 5 | お酒と食べ物は持ち込みのみ(デリバリー可)。当方は**お酒の販売・提供をしない**。火を使う器具・ホットプレート・鍋は不可(電子レンジと電気ケトルのみ)。全館禁煙(電子たばこを含む) | 酒類の販売免許や飲食店の営業許可がいらない形にする。火災・煙・臭いを防ぐ |
| 6 | 泥酔している人の入室を断る。一気飲みは禁止 | 急性アルコール中毒と事故の予防 |
| 7 | 汚した場合の追加清掃費:嘔吐は2万円、ゴミの分別違反・放置は3,000円、飲み物で汚した部分のタイルカーペット交換は実費 | 抑止と費用の回収 |
| 8 | 騒音センサーが反応したら3段階で対応する:①自動メッセージ ②ホストから電話 ③退室を求め、違約金を取る(返金なし) | 苦情が出る前に止める |
| 9 | 共用部(廊下・エレベーター・ゴミ置き場)では静かにし、たまらない。建物の出入口の前で話し込まない | 同じ建物のテナントと近隣への配慮 |

- 具体的な金額と文面は ai-writer が利用規約とポータルの設定に落とし込む。ポータルで設定できない項目は、規約と入室案内で伝える。
- 施設賠償責任保険が飲酒中の事故を補償の対象外にしていないか、ai-admin が加入前に確認する。

### 1-6. 物件の選び方(第3版)

**必須条件(1つでも満たさなければ見送る)**

1. 賃貸借契約書か覚書に「**レンタルスペースとしての時間貸し(第三者の利用)可**」と書面で書かれている
2. 同じく書面で、**飲酒を伴う利用**と、**6:00〜23:00の営業(入館)**が認められている
3. **24時間ゴミを出せるゴミ置き場が建物にあり**、時間貸しの利用者がそこへゴミを出すことを、管理規約・契約書・覚書のいずれかで**書面で認められている**(1-7)
4. 事業用(店舗・事務所)の契約である。住居用の部屋や、管理規約が住宅専用の分譲マンションは不可
5. **家賃(共益費込み)が7万円以下**。8万円が絶対の上限(8万円だと1年での回収はできない。第3章)
6. **物件取得費が45万円以下**(敷金・保証金は2ヶ月分以内、礼金は1ヶ月分以内が目安)。保証金が家賃の6ヶ月分以上の物件は見送る
7. **建物に住戸がない**(全フロアが事業用)。第2版の「同じ階と上下の階に住戸がない」から厳しくした
8. 駅から徒歩8分以内(第2版の5分以内から緩めた。家賃を下げるため)

**加点条件**

- **飲食店が入居しているビルの2階以上**(夜間の人通りと飲酒に慣れた建物で、24時間のゴミ置き場があることが多い)
- ターミナル駅から電車で10〜20分の、住宅地と飲食店街がある駅(家飲みの代わりとして、帰り道に寄れる)。ライブ会場や劇場に1本で行ける駅なら、なお良い
- 1階の路面店と地下は避ける(路上への音漏れと、地下の消防上の条件)
- エレベーターがある、6:00から入館できる、解約予告が3ヶ月以内
- フリーレント(入居後しばらく家賃が無料)を交渉できる

### 1-7. ゴミの扱い(U-06 の統一方針)

**決定:利用者が自分で分別し、建物の24時間ゴミ置き場へ捨てに行く。**第2版の推奨案「すべてお持ち帰り」は撤回する。

- 室内には分別用のゴミ箱(燃やすゴミ・缶・瓶・ペットボトル)とゴミ袋を置く。退室の15分前(22:45)までにゴミ置き場へ運ぶ。
- 分別できない物や大量のゴミ(段ボールをたくさん・瓶をケースごとなど)は持ち帰ってもらう。
- 入室案内には、ゴミ置き場までの道順を写真付きで載せる。退室時の写真にはゴミ置き場の写真も含めてもらう。
- **契約の前に書面で確認すること(必須)**:①時間貸しの利用者がゴミ置き場を使ってよいか ②24時間出せるか ③分別の区分(缶・瓶・ペットボトルを出せるか) ④費用(ビルの事業系ゴミ処理費を月いくら払うか) ⑤ゴミ置き場まで住戸や他のテナントの前を通らずに行けるか
- 利用者のゴミは事業系のゴミとして扱われ、地域の家庭ゴミ集積所には出せない可能性が高い【要確認:ai-researcher】。家庭ゴミ集積所しかない物件は見送る。
- 事業系ゴミの処理費として月5,000円を固定費に入れた(第3章)。

| 枠 | 定価 | 主力パック |
|---|---|---|
| 早朝 6〜9時 | 1,200円/時 | 朝の3時間パック 3,000円(身支度・観戦) |
| 平日昼 9〜17時 | 1,500円/時 | 昼飲み・推し活4時間パック 5,800円/撮影半日パック(4時間・商用料込み)6,800円 |

- 最低利用時間:早朝・平日は2時間、土日祝は3時間(1予約を長くして、清掃1回あたりの費用を薄めるため)
- **平均単価の目標は2,700円/時**(1年回収の条件)。土日祝の実効単価3,300〜3,400円と、平日夜の実効単価2,600円前後を保つのが前提。平日昼と早朝の比率が上がると、平均は2,500円前後に下がる
- 1予約の平均は**4時間**とする(晩酌は3〜4時間になりやすいため、第2版の4.7時間から短くした。U-18 の統一方針:第3版は4時間で計算)

### 2-2. 価格の運用ルール(第2版から継続)

1. オープニング価格(25%引き)は**開業1ヶ月目のみ**
2. 価格の見直しは月1回。開業後8週間は週ごとの数字で価格を動かさない
3. 値下げ競争には参加しない。写真・レビュー・ハウスルールの安心感で選ばれるようにする
4. 手数料(25〜35%)を引いた**手取りの単価**で判断する(免税事業者だと実質約33%)
5. パックを中心に売って、1予約の時間を短くしない

### 2-3. 入室・清掃の時間(U-03・U-04 の統一方針)

- 入室は予約の開始時刻から。暗証番号は予約時間内だけ使える(U-03:第2版の推奨案どおり)
- 清掃のための空き時間は**利用後30分のみ**(U-04:第2版の推奨案どおり)

### 2-4. 早朝枠と清掃の回し方

退室が23:00の日は、その夜のうちに清掃できない。翌朝の6時から早朝枠を売るには、前の夜に清掃を終えておく必要がある。

1. **夜の最後の利用が23:00に終わる日**は、翌日の最初の予約の前(9時以降)に清掃する。そのため、**翌朝の早朝枠は売らない**
2. **早朝枠は承認制で、前々日までの予約のみ**受け付ける。受けるのは、前の夜の予約が22:00までに終わる日だけ(22:00〜22:30に清掃)。夜22時以降に予約が入っている場合は、単価が高い夜を優先して早朝枠は断る
3. 早朝枠の稼働率の目標は低め(10%)にしている。早朝で稼ぐのではなく、「朝から使える部屋」という選ばれる理由を増やすのがねらい
4. 利用者が自分で片付けてゴミを出すので(1-7)、清掃の外注単価は**1回1,500円**を目標にする(第2版は2,000円)

## 3. 数値:1年回収は現実的か

### 3-1. 前提(第3版)

| 項目 | 値 | 第2版 |
|---|---|---|
| 稼働率の分母 | **月510時間**(17時間 × 30日) | 450時間 |
| 月の固定費 | **11.5万円**(家賃7万+光熱1.5万+通信0.5万+ツール0.5万+消耗品1万+保険0.3万+事業系ゴミ0.5万+雑費0.2万) | 16万円 |
| 手数料 | 30% | 同じ |
| 清掃 | 1回1,500円、1予約4時間(1時間あたり375円) | 2,000円・4.7時間 |
| 初期投資(運転資金を除く) | **110万円** | 250万円 |
| 運転資金 | **70万円**(固定費の約6ヶ月分) | 150万円 |
| 回収の定義 | 開業からの累積の営業利益(税引前・現金ベース)が初期投資に並んだ月 | 同じ |
| 月の損益の式 | 予約時間 ×(単価 × 0.7 − 375円)− 11.5万円 | — |
| 含めないもの | 減価償却・所得税・消費税の納税・季節変動・直接予約。**開業前の空家賃(約1ヶ月分)は初期投資の予備費で吸収する** | 同じ |

### 3-2. 1年回収に必要な数字(推奨目標)

| 項目 | 目標 |
|---|---|
| **初期投資の上限** | **110万円**(目標は100万円) |
| **家賃の上限** | **7万円**(共益費込み。絶対の上限は8万円) |
| **物件取得費の上限** | **45万円** |
| **内装費** | **25万円**(第2版の50万円から半分に) |
| **家具・AV** | **23万円**(中古中心。第2版は45万円) |
| **必要な稼働率**(510時間が分母) | **3ヶ月20%(月102時間)→ 6ヶ月30%(153時間)→ 12ヶ月40%(204時間)** |
| **必要な平均単価** | **2,700円/時** |
| 損益分岐 | 月76時間(稼働率15%) |

この条件で月ごとに計算すると、次のようになる(1ヶ月目は稼働率10%・25%引き、その後は上の稼働率へ直線的に伸びる)。

| 月 | 稼働率 | 月の営業損益 | 累積 |
|---|---|---|---|
| 1 | 10% | −6.2万円 | −6.2万円 |
| 3 | 20% | +4.0万円 | −2.1万円 |
| 6 | 30% | +11.7万円 | +25.2万円 |
| 9 | 35% | +15.5万円 | +67.9万円 |
| 11 | 38% | +18.1万円 | +102.9万円 |
| **12** | **40%** | **+19.4万円**(売上約55万円) | **+122.3万円 → 12ヶ月目に110万円を回収** |

### 3-3. 正直な評価

**1年回収は「不可能ではないが、余裕がない」。**5つの条件のうち1つでも外れると、13ヶ月目以降にずれ込む。

| シナリオ | 条件 | 12ヶ月時点の累積 | 回収 |
|---|---|---|---|
| **達成**(3-2) | 家賃7万・初期110万・単価2,700円・清掃1,500円・稼働率 20→30→40% | 約+122万円 | **12ヶ月目** |
| **基本** | 上の条件で、単価だけ**2,500円** | 約+98万円 | **13ヶ月目** |
| **慎重** | 単価2,400円・清掃2,000円・稼働率 16→25→35%(立ち上げが遅い) | 約+33万円 | **20ヶ月目前後** |

**12ヶ月時点の累積利益に効く要素(達成シナリオが基準)**

| 変化 | 12ヶ月の累積への影響 |
|---|---|
| 毎月の稼働率が5ポイント低い | **約−46万円**(一番大きい) |
| 平均単価が200円低い | 約−24万円 |
| 清掃が1回500円高い | 約−22万円 |
| 家賃が1万円高い | 約−12万円(取得費も増えるので、回収は13ヶ月目にずれる) |

- **一番の不安は「立ち上げの速さ」**。第2版では12ヶ月目の目標を450時間中45%(約200時間)にしていた。第3版の12ヶ月40%(204時間)は、**時間数で見ると第2版と同じ水準**で、分母が増えた分だけ%が下がって見えるだけ。都心から離れた安い物件で、第2版と同じ時間数を売る必要がある。
- 単価2,700円は、第2版の資料にある新宿・渋谷の平均(約2,700円)と同じ水準。安い立地で届かせるには、写真・レビュー・「推しと晩酌」の分かりやすさで勝つ必要がある。
- **逆に言えば、初期投資を110万円に抑えることで、失敗したときの損失も小さくなる**。撤退しても、敷金の返ってくる分を差し引けば、損失はおおよそ100万円以内に収まる(第2版では250万円)。

**判断:目標は「12ヶ月で回収」を掲げる。ただし、資金計画と撤退基準は「18ヶ月で回収」を前提にする。**12ヶ月で回収できなくても、それだけでは失敗とせず、第3-5章の基準で継続か撤退かを判断する。

### 3-4. 1年回収のための逆算(初期投資の上限の根拠)

- 達成シナリオでは、12ヶ月の累積利益が約122万円になる。安全のために約1割の余裕を見て、**初期投資の上限を110万円**とした。
- 単価が2,500円(基本シナリオ)でも12ヶ月で回収したいなら、初期投資は**約95万円以下**にする必要がある(12ヶ月の累積が約98万円のため)。物件取得費をフリーレントや礼金なしの交渉で35万円程度まで下げられれば届く。**そのため「目標100万円」とした**。
- 家賃が8万円になると、固定費と取得費が増えて、達成シナリオでも13ヶ月目にずれる。**7万円を超える物件は、1年回収をあきらめる前提でしか契約しない**。

### 3-5. 撤退基準(第3版。開業前に社長と合意しておく)

損益分岐が稼働率15〜16%まで下がったので、基準も付け直した。稼働率はすべて510時間が分母。

| 区分 | 条件 | 対応 |
|---|---|---|
| 即時撤退 | 大家・管理会社から契約違反や苦情で書面の是正要求があり、改善できない。または行政から指導を受けた | すぐに撤退の準備を始める |
| 注意 | 3ヶ月時点で稼働率12%未満 | 写真・掲載文・価格を見直す |
| 黄信号 | 6ヶ月時点で稼働率20%未満 | 用途・価格・写真を見直す(2ヶ月×2回まで) |
| 撤退判断 | 見直しを2回しても18%未満、**または12ヶ月時点で20%未満** | 解約を予告する |
| 条件付き継続 | 12ヶ月時点で20〜30% | 単月黒字が続いていて、直近3ヶ月の稼働率が上向きなら継続。**18ヶ月目に30%未満なら撤退** |
| 継続 | 12ヶ月時点で30%以上 | 継続する |
| 1年回収の判定 | 12ヶ月時点の累積利益が初期投資の80%以上なら「ほぼ計画どおり」。50%未満なら「18ヶ月回収の計画」に切り替える(これだけでは撤退しない) | ai-analyst が12ヶ月のレビューで報告する |
| 資金ライン | 運転資金が固定費3ヶ月分(**35万円**)を下回った | 追加の投資はせず、撤退か縮小を決める |
| 上振れ | 12ヶ月時点で稼働率50%超が3ヶ月続く | 2室目の検討を始める(社長の判断) |

## 9. リスクと前提の注意

- 第3版の数値は ai-ceo の手計算による暫定値。ai-analyst の検算で確定させる。
- **家賃7万円で、必須条件8つをすべて満たす物件が見つかるかどうかは確認できていない**。見つからない場合は「家賃8万円で13ヶ月回収」か「条件を緩める」かを社長が判断する。ただし、書面での承諾(必須条件1〜3)と住戸がないこと(7)は緩めない。
- 晩酌は単価と需要を押し上げる一方で、騒音・汚損・酔った人のトラブルが増える。1回の契約解除で投資の大半を失う構造は第2版と変わらない。
- 推し活はイベントの時期で需要が変動し、晩酌は給料日と週末に集中しやすい。月ごとの季節変動は試算に入れていない。
- 平均単価2,700円は、安い立地では相場の上限に近い。届かなければ基本シナリオ(13ヶ月目)になる。
- 回収の試算には、減価償却・所得税・消費税の納税・季節変動を含めていない。

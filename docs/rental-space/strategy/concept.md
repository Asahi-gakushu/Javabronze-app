## 結論(5行)

1. **コンセプト**:「6人までの“静かに盛り上がる”シアター&撮影ルーム」。主軸は休日・平日夜の少人数プライベート利用(推し活・上映会・誕生日会)、副軸は平日昼の撮影・会議・オンライン面接。
2. **差別化**:大画面プロジェクター+装飾しやすい壁+白壁の撮影面。「定員6名・22時退室・音量上限つき」を最初から売りにして、騒音リスクを抑えながら単価の高い休日需要を取る。
3. **料金**:平日昼1,500円/時、平日夜2,500円/時、休日3,000〜3,500円/時。休日は「3時間」「5時間」パックを主力にする。実際の平均単価の目標は2,400円/時以上。
4. **数値目標**:稼働率(8〜23時の15時間営業ベース)を3ヶ月20%、6ヶ月30%(単月黒字)、12ヶ月45%。**初期投資250万円は開業から約3年(35ヶ月目)で回収する**。12ヶ月で30%未満なら撤退、30〜35%なら18ヶ月目を期限とした条件付き継続。
5. **物件で一番大事なのは「家賃12万円以下」と「時間貸しOKの書面承諾」**。この2つを満たせない物件は、どれほど立地が良くても見送る。家賃は開業後に変えられず、損益分岐を決める最大の要因になる。

## 1. 事業コンセプト

### 1-1. 推奨案

| 項目 | 内容 |
|---|---|
| コンセプト名(仮) | 6人までのシアター&撮影ルーム |
| 主軸(売上の約65%を想定) | **休日・平日夜の少人数プライベート利用**:推し活(上映会・生誕祭)、誕生日会、女子会、ボードゲーム、映画・スポーツ観戦 |
| 副軸(稼働の下支え) | **平日昼の撮影・ビジネス利用**:物撮り・SNS撮影・動画収録、少人数会議、面接、オンライン面接や商談、テレワーク |
| 定員 | 6名(15㎡想定。10㎡なら4名) |
| 営業時間 | 8:00〜23:00(パーティー系は22:00退室)。深夜・宿泊・仮眠プランは作らない(旅館業法と騒音の対策) |
| 運営 | 無人運営(スマートロック+防犯カメラ+騒音センサー)、清掃は外注。立ち上げ期は社長が自分で清掃してコストと品質を確かめる選択肢もある |

### 1-2. 平日と休日の使い分け

| 時間帯 | 主な用途 | 室内の見せ方 | 料金帯 |
|---|---|---|---|
| 平日 8〜17時 | 撮影、会議、面接、テレワーク | テーブルを中央に置き、白壁側をすぐ使える状態に | 低(1,500円/時) |
| 平日 17〜23時 | 仕事帰りの上映会・誕生日会、勉強会 | シアター配置 | 中(2,500円/時) |
| 土日祝 | 推し活・パーティー・撮影(商用) | シアター配置+装飾OK | 高(3,000〜3,500円/時) |

- 家具は「会議配置」と「シアター配置」を5分で切り替えられるものにする(ai-designer の指示書に入れる)。

### 1-3. 差別化ポイント(なぜ選ばれるか)

1. **大画面+音**:100インチ以上のプロジェクターと、音量上限を設定したサウンドバー。「上映会ができる部屋」は写真1枚で違いが伝わり、検索結果で目立つ。
2. **装飾しやすい壁**:推し活の飾り付け(ガーランド・ぬいぐるみ・アクリルスタンド)ができる有孔ボードやピンレールの壁。貸し出し用の装飾キットを用意する。壁紙の傷みも防げる。
3. **白壁の撮影面と照明**:平日昼の撮影需要を取るための設備。商用撮影は別料金にする。
4. **「静かなパーティー」を最初からルールにする**:定員6名、22時退室、音量上限、共用部での会話禁止を掲載文に明記する。騒がしいグループを予約の段階で遠ざけ、近隣トラブルと退去リスクを減らす。

### 1-4. 不採用にした案と理由

| 案 | 見送る理由 |
|---|---|
| パーティー(大人数・飲酒中心)を主軸 | 単価は最も高いが、騒音苦情と契約解除が失敗例の上位(レポート第6章)。1室しかないので、1回の退去で投資がすべて失われる |
| 会議室のみ | 騒音リスクは低いが、単価1,500円/時でも損益分岐の稼働率が**約57%**になる(単価1,250円なら約79%)。会議利用は1予約が1〜2時間と短く、清掃費でさらに悪化する |
| ダンス・楽器レッスン | 15㎡では狭いうえ、防音と床の工事で予算を超える |
| テレワーク個室のみ | 単価が低すぎる(300〜1,000円/時)。副次的な用途にとどめる |

### 1-5. エリア・物件の選定基準

**必須条件(1つでも欠けたら見送り)**

1. 賃貸借契約書か覚書に「レンタルスペースとしての時間貸し(第三者利用)可」と**書面で明記**されている
2. 事業用(店舗・事務所)の契約である。住居用の部屋や、管理規約が住宅専用の分譲マンションは不可
3. 家賃(共益費込み)が12万円/月以下。1万円上がるごとに損益分岐の稼働率が約1.7ポイント悪化する(家賃10万円なら取得費も減り、回収は開業から約28ヶ月目に早まる)
4. 駅から徒歩5分以内
5. 同じフロアと上下の階に住戸がない(騒音苦情の予防)

**加点条件**

- 複数路線が使える駅、または大きなターミナル駅から電車で1〜2駅。新宿・渋谷の中心部は家賃と競合が重いので第一候補にしない
- 半径500m以内に「シアター・推し活」系の競合が少ない。ただし、パーティー系の掲載が多いのは需要がある証拠として前向きに見る
- 近くにライブ会場・劇場・大学・専門学校がある(推し活・撮影の需要)
- エレベーターがあり、夜間の出入りが自由で、看板や案内表示が出せる
- 解約予告期間が短い(3ヶ月以内が望ましい。撤退時の損失を小さくするため)

**候補駅の絞り込み方**:ai-marketer が2〜3駅を選び、各駅についてポータルの掲載数・平均時間単価・レビュー数・家賃相場を比較表にする。社長はその表を見て駅を決める。

## 2. 料金設計の方針

### 2-1. 時間単価の目安(開業時)

| 枠 | 定価 | 根拠 |
|---|---|---|
| 平日 8〜17時 | 1,500円/時 | 会議室相場800〜2,000円の上側。撮影設備がある分を上乗せ |
| 平日 17〜23時 | 2,500円/時 | 新宿・渋谷の平均2,700円よりやや低め |
| 土日祝 | 3,000〜3,500円/時 | パーティーの平均予約単価は1.6〜1.7万円(レポート第3章)。5時間パックでこれに合わせる |
| 商用撮影 | 通常料金+1,000円/時 | 機材の搬入や壁の消耗分 |

- 最低利用時間:平日は1時間、休日は2時間(清掃1回あたりの費用を薄めるため)
- 清掃は利用後30分のバッファを予約不可の時間として確保する

### 2-2. パック料金(主力商品)

| パック | 目安価格 | 狙い |
|---|---|---|
| 休日 昼3時間パック | 9,800円 | 推し活・誕生日会の入口 |
| 休日 5時間パック | 14,800円 | 1予約あたりの平均(4.7時間・1.3万〜1.7万円)に合わせた主力 |
| 平日夜 上映会パック(18〜22時) | 8,800円 | 平日夜を埋める |
| 平日 撮影半日パック(4時間) | 6,800円 | 撮影事業者・個人クリエイターの定期利用 |
| 平日 定期利用(法人・教室向け) | 月4回以上で10%引き | ai-sales が営業する。手数料のかからない直接契約にできるかは規約確認が必要 |

### 2-3. 価格の運用ルール

1. **オープニング価格(20〜30%引き)は開業1ヶ月目のみ**とし、2ヶ月目からは定価に戻す。この期間にレビューを最短で集める(目標:3ヶ月で20件、平均4.7以上)
2. 2ヶ月目以降は、ai-analyst の時間帯別稼働率を見て毎月1回だけ価格を調整する。稼働率60%超の枠は値上げ、10%未満の枠は直前割を設定。開業後8週間は予約数が少ないので、週次の数字では価格を動かさない
3. 値下げ競争には参加しない。単価で負けそうなときは、設備と装飾キットの写真で差をつける
4. 手数料(25〜35%)を必ず差し引いて判断する。**手取りの単価で考える**。免税事業者のままだと手数料にかかる消費税を差し引けず、実質の手数料率は約33%になる
5. 1予約あたりの時間を短くしない(4.7時間→3時間になると、12ヶ月目の月利益は約4.9万円減る)。パック中心の販売を続ける

## 3. 数値目標と撤退基準

### 3-1. 前提

- 稼働率 = 予約された時間 ÷ 月450時間(8〜23時 × 30日)
- 月の固定費は16万円(家賃12万円を含む)、手数料は30%、清掃は1回2,000円、1予約あたり平均4.7時間
- 初期投資は約250万円(運転資金を除く)
- 損益の計算式:売上 × 0.7 − 清掃費(予約時間 ÷ 4.7 × 2,000円) − 固定費16万円
- 平均単価:定価で運用(オープニング割引は1ヶ月目のみ)。3ヶ月目の2,200円は、立ち上げ期で土日祝の予約がまだ少なく、単価の低い平日昼の比率が高いことを見込んだ値

### 3-2. 目標

| 時点 | 稼働率 | 月の予約時間 | 平均単価 | 月売上(税抜) | 月の営業損益(概算) | 補助KPI |
|---|---|---|---|---|---|---|
| 開業3ヶ月 | 20% | 90時間 | 2,200円(立ち上げ期の用途構成) | **約20万円** | **約−6万円** | レビュー20件・平均4.7以上 |
| 開業6ヶ月 | 30% | 135時間 | 2,400円 | **約32万円** | **約+1万円(単月黒字)** | リピート率20%、平日昼の稼働率15% |
| 開業12ヶ月 | 45% | 約200時間 | 2,500円 | **約50万円** | **約+10〜11万円** | 平日の法人・定期利用を月8件 |

- 12ヶ月時点で40%(約45万円、月の利益は約+8万円)なら「合格」、45%は「目標」とする。
- **初期投資の回収**:12ヶ月目に45%に達し、その後も横ばいの場合、立ち上げ期の赤字(5ヶ月目が底で累積約−26万円)を含めて**開業から約3年(35ヶ月目)で回収**する。45%に達した時点から数えると約2年。
- 稼働率別の回収時期(開業起点、12ヶ月目以降は横ばいの場合):

| 12ヶ月目以降の稼働率 | 月の利益 | 開業からの回収 |
|---|---|---|
| 30%(撤退ライン) | 約+1.7万円 | 120ヶ月超(事実上回収できない) |
| 35% | 約+4.6万円 | 67ヶ月目 |
| 40%(合格) | 約+7.6万円 | 45ヶ月目 |
| 45%(目標) | 約+10.5万円 | 35ヶ月目 |
| 50% | 約+13.5万円 | 29ヶ月目 |

- 開業から2年で回収したい場合は、立ち上げを前倒しするか、45%を超える稼働率が必要になる(50%で横ばいでも29ヶ月目)。
- 目標どおり進めば、運転資金は最も少ない時でも約124万円残り、資金ライン48万円には届かない。

### 3-3. 撤退基準(開業前に社長と合意しておく)

| 区分 | 条件 | 対応 |
|---|---|---|
| 即時撤退 | 大家・管理会社から契約違反や苦情で書面の是正要求があり、改善できない。または行政から指導を受けた | すぐに撤退の準備を始める |
| 黄信号 | 6ヶ月時点で稼働率20%未満 | 用途・価格・写真を見直す(2ヶ月×2回まで) |
| 撤退判断 | 見直し2回の後も稼働率が25%未満、**または12ヶ月時点で30%未満** | 解約を予告する。予告期間の分を見込んで早めに判断する |
| **条件付き継続** | **12ヶ月時点で30〜35%** | 下の「3-3-1」に従う。期限は18ヶ月目 |
| 継続 | 12ヶ月時点で35%以上 | 継続する。40%未満の間は、四半期ごとに改善策を1つ実施する |
| 資金ライン | 手元の運転資金が固定費3ヶ月分(48万円)を下回った | 追加の投資はせず、撤退か縮小を決める |
| 上振れ | 12ヶ月時点で稼働率50%超を3ヶ月連続 | 2室目の検討を始める(社長の判断) |

#### 3-3-1. 12ヶ月時点で30〜35%の場合(推奨案:18ヶ月目を期限とした条件付き継続)

30%では月の利益が約+1.7万円しかなく、初期投資は事実上回収できない。35%でも回収は67ヶ月目になる。「赤字ではないが回収もできない」状態がずるずる続くのを防ぐため、次のルールにする。

1. **継続の条件(すべて満たす)**:単月黒字が続いている/直近3ヶ月の稼働率が上向き(3ヶ月で+3ポイント以上)/運転資金が48万円以上ある
2. **改善策を2つ実施する**(13〜15ヶ月目):土日祝の単価の見直し(+300円/時で月約+2.1万円)、清掃単価の引き下げ(1回1,500円で月約+2.2万円)、手数料の低いポータルや直接予約の比率を上げる、など。ai-analyst が効果の大きい順に提案する
3. **15ヶ月目に中間判定**:稼働率が35%未満なら解約予告の準備に入る(予告期間が3ヶ月なら、ここで予告すれば18ヶ月目に退去できる)
4. **18ヶ月目に最終判定**:稼働率40%以上なら継続、40%未満なら撤退する
5. 継続の条件を1つでも満たさなくなったら、期限前でも撤退判断に移る

## 6. リスクと前提の注意

- 本メモの時間単価と稼働率の目標は、ポータル上の平均値と業界記事(一部は古いデータ・二次情報)をもとにした試算。物件が決まったら、その駅の競合データで ai-analyst が引き直す。
- 「推し活」需要は季節やイベントで変動する。平日昼の撮影・法人利用で下支えできないと、12ヶ月45%は届かない。
- 平均単価2,400〜2,500円は、土日祝がよく埋まる(予約時間の約半分が土日祝)ことが前提。平日昼の比率が上がると平均単価は下がる。
- 手数料率(特にスペイシー)と、直接予約への誘導の可否は未確認。確認するまでは直接予約を収支計画に入れない。
- 回収時期の試算には減価償却・所得税・消費税の納税・開業前の空家賃・季節変動を含めていない。
